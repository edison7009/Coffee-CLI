# Contributing to Coffee CLI / 贡献指南

This repository only builds and publishes Coffee CLI releases. It is not an open-source project, takes part in
no open-source activity, and does not accept pull requests. Bug reports are welcome as issues.

本仓库仅用于编译和发布 Coffee CLI 安装包，不是开源项目，不参与任何开源活动，不接受 Pull Request。欢迎通过 Issue 反馈问题。

Contributions made up to v4.1.1 were accepted under the Contributor License Agreement in that version of
this file. / v4.1.1 及之前的贡献依据当时本文件中的贡献者许可协议（CLA）接收。
