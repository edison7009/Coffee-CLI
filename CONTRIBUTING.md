# Contributing to Coffee CLI / 贡献指南

This repository publishes Coffee CLI releases. It does not accept pull requests and is not actively
maintained. Bug reports are welcome as issues.

本仓库用于发布 Coffee CLI 安装包，不接受 Pull Request，也不做积极维护。欢迎通过 Issue 反馈问题。

Contributions made up to v4.1.1 were accepted under the Contributor License Agreement in that version of
this file. / v4.1.1 及之前的贡献依据当时本文件中的贡献者许可协议（CLA）接收。
