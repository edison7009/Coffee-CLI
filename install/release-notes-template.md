### Coffee CLI v3.8.9 · Pi 桌面式对话上线

- **Pi 桌面式对话：** 在启动台的 Pi 卡片上选择 Desktop，就能用和 Claude 一样的对话界面使用 Pi。修改代码时左右对照显示改动，运行命令时实时显示输出；输入框旁可以切换模型和思考强度，还能查看上下文占用、缓存命中率和本次会话的花费。欢迎页和工作中的动画都用了 Pi 自己的标志。感谢 GitHub Issues 里的建议。
- **Pi 应用配置补全：** Pi 支持浏览器控制和电脑控制，可以在多智能体编排里作为子会话（需要在应用配置里手动开启），使用统计也会计入 Pi 的用量。
- **左侧列表切换更清楚：** “会话列表 / 项目分类”改为点右侧的三横杠按钮，在菜单里选择；项目分组之间留出了更大的间距。
- **修复：** Pi 的标签页显示文件夹名而不是会话名；Pi 和 Oh My Pi 的新会话有时在历史里重复出现；Codex、OpenCode 桌面式完成后没有提示音。

### Coffee CLI v3.8.9 · Pi Comes to the Desktop View

- **Pi desktop conversations:** Choose Desktop on the Pi card in the launchpad to use Pi in the same conversation view as Claude. Code edits show side by side and commands stream their output; beside the input box you can switch models and thinking levels, and see context use, the cache hit rate and the session cost. The welcome screen and the working animation use Pi's own logo. Thanks for the suggestion in GitHub Issues.
- **Pi in app settings:** Pi works with browser control and computer control, can be a worker in multi-agent orchestration (turn it on in app settings), and its usage now counts in usage statistics.
- **Clearer sidebar switch:** Switch between the session list and projects from the three-line button on the right; project groups have more room between them.
- **Fixes:** Pi tabs showing the folder name instead of the conversation; new Pi and Oh My Pi sessions sometimes appearing twice in history; no completion sound for Codex and OpenCode desktop conversations.

### Coffee CLI v3.8.9 · Pi がデスクトップ表示に対応

- **Pi のデスクトップ会話：** 起動画面の Pi カードで Desktop を選ぶと、Claude と同じ会話画面で Pi を使えます。コードの変更は左右に並べて表示され、コマンドの出力はリアルタイムで流れます。入力欄の横でモデルと思考の強さを切り替えられ、コンテキストの使用量、キャッシュのヒット率、セッションの費用も確認できます。ようこそ画面と作業中のアニメーションには Pi 自身のロゴを使っています。GitHub Issues でのご提案に感謝します。
- **アプリ設定で Pi に対応：** Pi でブラウザ操作とコンピューター操作が使えるようになり、マルチエージェント連携のサブ会話にもできます（アプリ設定でオンにしてください）。使用量の統計にも Pi が含まれます。
- **サイドバーの切り替えをわかりやすく：** セッション一覧とプロジェクト別は、右側の三本線ボタンのメニューから切り替えます。プロジェクトのグループ間にも余白を広く取りました。

### Coffee CLI v3.8.9 · Pi 데스크톱 대화 보기 지원

- **Pi 데스크톱 대화:** 실행 화면의 Pi 카드에서 Desktop을 고르면 Claude와 같은 대화 화면에서 Pi를 쓸 수 있습니다. 코드 수정은 좌우로 나란히 보여 주고, 명령 출력은 실시간으로 표시됩니다. 입력창 옆에서 모델과 생각 강도를 바꿀 수 있고, 컨텍스트 사용량, 캐시 적중률, 세션 비용도 확인할 수 있습니다. 시작 화면과 작업 중 애니메이션에는 Pi 고유의 로고를 사용했습니다. GitHub Issues에 남겨 주신 제안에 감사드립니다.
- **앱 설정에서 Pi 지원:** Pi에서 브라우저 제어와 컴퓨터 제어를 쓸 수 있고, 멀티 에이전트 연동의 하위 세션으로도 쓸 수 있습니다(앱 설정에서 켜 주세요). 사용량 통계에도 Pi가 포함됩니다.
- **사이드바 전환을 더 알기 쉽게:** 세션 목록과 프로젝트별 보기는 오른쪽 세 줄 버튼의 메뉴에서 바꿉니다. 프로젝트 그룹 사이 간격도 넓혔습니다.
- **수정:** Pi 탭에 대화 이름 대신 폴더 이름이 표시되던 문제, Pi와 Oh My Pi의 새 세션이 기록에 두 번 보이던 문제, Codex와 OpenCode 데스크톱 대화에서 완료 알림음이 나지 않던 문제.
