### Coffee CLI v3.7.2 · 会话状态缓存修复

- **状态缓存。** PR 与 CI 标志保存在本地，重启或重新打开列表时立即恢复，再于后台静默更新。
- **刷新稳定性。** 网络失败或限流时保留已有状态，结果未变时避免重绘标志，成功查询后正常更新。

### Coffee CLI v3.7.2 · Session Status Cache Fix

- **Status cache.** Save PR and CI marks locally, restore them immediately after restarting or reopening the list, and refresh silently in the background.
- **Stable refresh.** Keep known states during network failures or rate limits, avoid redrawing unchanged marks, and apply successful updates normally.

### Coffee CLI v3.7.2 · 對話狀態快取修復

- **狀態快取。** PR 與 CI 標誌儲存在本機，重新啟動或開啟列表時立即恢復，再於背景靜默更新。
- **更新穩定性。** 網路失敗或限流時保留既有狀態，結果未變時避免重繪標誌，成功查詢後正常更新。

</details>

### Coffee CLI v3.7.2 · 会話ステータスのキャッシュ修正

- **状態キャッシュ。** PR・CI マークをローカルに保存し、再起動や一覧を開き直した際にすぐ復元します。最新の状態はバックグラウンドで静かに取得します。
