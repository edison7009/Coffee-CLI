### Coffee CLI v3.9.9 · 语音输入紧急修复

- **语音输入：** 修复 macOS 上打开语音输入设置就闪退的问题。
- **macOS 系统语音：** 没开听写时会提示到“系统设置 → 键盘 → 听写”中打开，不再只显示“语音输入失败”。
- **Qwen Code：** Qwen 更名为 Qwen Code，并换上新图标。
- **界面：** 右上角的左右面板和键盘按钮统一为同一套图标风格。

</details>

### Coffee CLI v3.9.9 · Voice Input Hotfix

- **Voice input:** Fixed a crash on macOS when opening the voice input settings.
- **macOS system speech:** When Dictation is off, you're now told to turn it on in System Settings → Keyboard → Dictation instead of seeing a generic failure.
- **Qwen Code:** Qwen is now Qwen Code, with its new icon.
- **Interface:** The left panel, right panel and keyboard buttons in the top-right corner now share one icon style.

### Coffee CLI v3.9.9 · 語音輸入緊急修復

- **語音輸入：** 修復 macOS 上開啟語音輸入設定就閃退的問題。

### Coffee CLI v3.9.9 · 음성 입력 긴급 수정
