### Coffee CLI v3.7.4 · Agent Configuration and Collaboration

- **Agent configuration.** Manage favorite tools and global memory in a dedicated page, with direct editing, conflict protection, and installation status.
- **Skill management.** Discover skills from public upstream sources and install, update, or remove them per tool. Cached lists, skeletons, and avatar fallbacks improve loading.
- **Computer and browser control.** Built-in computer control on Windows and dedicated Chrome/Edge windows for browser control. Enable each tool separately without adding hooks.
- **Multi-agent orchestration.** Claude can delegate to Claude, Codex, and OpenCode. Child tabs follow the parent session and retain task states, questions, and results.
- **Statistics and updates.** View a full year of activity and check or update supported favorite CLIs with a new animated update indicator.
- **Fixes and verification.** Fix modified Enter in native terminals and flickering thinking controls; expand browser, native protocol, and release regression checks.

### Coffee CLI v3.7.4 · 에이전트 설정과 협업

- **에이전트 설정.** 즐겨 쓰는 도구와 전역 메모리를 전용 화면에서 관리하며 직접 편집, 충돌 보호, 설치 상태 표시를 지원합니다.
- **스킬 관리.** 공개 소스에서 스킬을 찾아 도구별로 설치·업데이트·삭제합니다. 캐시, 스켈레톤 화면, 대체 아바타로 로딩을 개선했습니다.
- **컴퓨터·브라우저 제어.** Windows 내장 컴퓨터 제어와 독립 Chrome/Edge 창을 통한 브라우저 제어를 제공합니다. Hook 추가 없이 도구별로 켤 수 있습니다.
- **멀티 에이전트 오케스트레이션.** Claude가 Claude, Codex, OpenCode에 작업을 위임합니다. 하위 탭은 부모 옆에 표시되며 상태, 질문, 결과를 유지합니다.
- **통계와 업데이트.** 1년 활동 히트맵과 지원 CLI의 업데이트 확인·원클릭 업데이트를 추가하고 진행 중에는 빛점 애니메이션을 표시합니다.
- **수정과 검증.** 기본 터미널의 조합 Enter 줄바꿈과 사고 설정 깜박임을 수정하고 브라우저, 네이티브 프로토콜, 출시 회귀 검사를 확대했습니다.
