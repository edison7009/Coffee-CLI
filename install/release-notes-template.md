### Coffee CLI v3.9.0 · 更省资源，窗口更顺手

- **修复 GPU 占用高：** 左上角标题去掉了一直冒热气的咖啡杯动画，空闲时不再反复重绘整个窗口，Windows 上的 GPU 占用明显下降。感谢 GitHub Issues 里的反馈。
- **窗口更顺手：** 默认窗口改得更小，13 寸笔记本也放得下；关闭后会记住窗口的大小和位置，下次原样打开。左侧栏默认更窄，给中间留出更多空间。
- **按工具查看会话：** 左侧列表的三横杠菜单新增“应用工具”，可以只看某一个常用工具的会话，子会话照常跟在主会话下面。
- **更清爽的细节：** 工具卡片的更新按钮只显示“更新”，版本号放在悬停提示里；macOS 上标题和红绿灯居中对齐。

### Coffee CLI v3.9.0 · Lighter on Your GPU, Easier Windows

- **Lower GPU use:** The steaming cup in the top-left title is gone. The app no longer redraws the whole window while idle, which noticeably cuts GPU use on Windows. Thanks for the report in GitHub Issues.
- **Easier windows:** The window opens smaller, so it fits 13-inch laptops, and reopens at the size and place you left it. The sidebar starts narrower, leaving more room in the middle.
- **Sessions by tool:** The three-line menu above the sidebar list has a new Tools option to show one favourite tool's sessions. Worker sessions still appear under their main session.
- **Cleaner details:** A tool card's update button now just says Update, with the versions in its tip; on macOS the title lines up with the traffic lights.

### Coffee CLI v3.9.0 · GPU にやさしく、ウィンドウがもっと使いやすく

- **GPU 使用率を改善：** 左上のタイトルから湯気が立ち続けるカップのアニメーションをなくしました。待機中にウィンドウ全体を描き直し続けることがなくなり、Windows での GPU 使用率が大きく下がります。GitHub Issues でのご報告に感謝します。
- **ウィンドウがもっと使いやすく：** 初期サイズを小さくし、13 インチのノートパソコンにも収まるようにしました。閉じたときのサイズと位置を覚え、次回はそのまま開きます。サイドバーの初期幅も狭くし、中央を広く使えます。
- **ツールごとに会話を表示：** サイドバー一覧の三本線メニューに「ツール別」を追加し、よく使うツールひとつの会話だけを表示できます。サブ会話はこれまでどおりメイン会話の下に表示されます。
- **細部をすっきり：** ツールカードの更新ボタンは「更新」だけを表示し、バージョンはツールチップに表示します。macOS ではタイトルが信号ボタンの中央にそろいます。

</details>

### Coffee CLI v3.9.0 · GPU 부담은 줄이고, 창은 더 편하게

- **GPU 사용량 개선:** 왼쪽 위 제목에서 김이 계속 오르던 커피잔 애니메이션을 없앴습니다. 대기 중에 창 전체를 계속 다시 그리지 않아 Windows에서 GPU 사용량이 크게 줄어듭니다. GitHub Issues에 남겨 주신 제보에 감사드립니다.
- **더 편한 창:** 기본 창 크기를 줄여 13인치 노트북에도 들어맞습니다. 닫을 때의 크기와 위치를 기억했다가 다음에 그대로 엽니다. 사이드바 기본 폭도 줄여 가운데를 더 넓게 씁니다.
- **도구별 세션 보기:** 사이드바 목록의 세 줄 메뉴에 「도구별」이 추가되어 자주 쓰는 도구 하나의 세션만 볼 수 있습니다. 하위 세션은 지금처럼 메인 세션 아래에 표시됩니다.
- **더 깔끔한 세부 사항:** 도구 카드의 업데이트 버튼은 「업데이트」만 표시하고 버전은 툴팁에 보여 줍니다. macOS에서는 제목이 신호등 버튼과 가운데로 맞춰집니다.
