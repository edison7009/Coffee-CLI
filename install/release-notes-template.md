### Coffee CLI v3.9.8 · 预输入改版与优先协作

- **预输入：** 便签改为只读，最多显示三行，点一下就放进当前输入框，确认后再发送；悬停显示删除。去掉了添加、编辑、复制和展开。
- **输入框：** “保存到预输入”旁新增清空按钮，两个按钮骑在输入框上边缘，出现和消失都带淡入淡出。
- **多智能体编排：** 输入框里的编排标识可以点开，为当前对话选择“自主决策”或优先协作的助手。
- **Claude 与 Codex 对话：** Claude 显示缓存状态，Codex 支持计划审批，两者都能轻量续接对话。
- **语音输入：** 新增更多原生语音通道并自动匹配；Claude 登录过期时会提示打开一次 Claude Code 续期。
- **改进与修复：** 设置页打开和关闭带动画；更新标签不再跳动，加载转圈不再上下漂移。

### Coffee CLI v3.9.8 · Pre-input Rework and Preferred Workers

- **Pre-input:** Notes are read-only and show up to three lines. A click puts one into the current composer so you can check it before sending; hover to delete. Add, edit, copy and expand are gone.
- **Composer:** A clear button joins "Save to pre-input". Both sit on the composer's top edge and fade in and out as they appear.
- **Multi-agent orchestration:** The orchestration badge in the composer opens a picker: let the AI decide, or prefer one assistant for this conversation.
- **Claude and Codex conversations:** Claude shows its cache status, Codex supports plan approval, and both can continue a conversation lightly.
- **Voice input:** More native speech channels, matched automatically. An expired Claude sign-in now tells you to open Claude Code once to renew it.
- **Improvements and fixes:** The settings page animates in and out. Update labels no longer shift, and the loading spinner no longer drifts.

- **プレ入力：** メモは読み取り専用で最大 3 行表示です。クリックすると現在の入力欄に入り、確認してから送信できます。ホバーで削除が現れます。追加・編集・コピー・展開はなくなりました。

### Coffee CLI v3.9.8 · 사전 입력 개편과 우선 협업

- **사전 입력:** 메모는 읽기 전용이며 최대 세 줄까지 보입니다. 클릭하면 현재 입력창에 들어가 확인한 뒤 보낼 수 있고, 마우스를 올리면 삭제가 나타납니다. 추가, 편집, 복사, 펼치기는 없어졌습니다.
- **입력창:** "사전 입력에 저장" 옆에 지우기 버튼이 추가되었습니다. 두 버튼은 입력창 위쪽 가장자리에 걸쳐 있으며 나타나고 사라질 때 서서히 표시됩니다.
- **멀티 에이전트 오케스트레이션:** 입력창의 오케스트레이션 표시를 눌러 이 대화에서 AI에게 맡길지, 우선 협업할 어시스턴트를 고를 수 있습니다.
- **Claude와 Codex 대화:** Claude는 캐시 상태를 보여 주고 Codex는 계획 승인을 지원하며, 둘 다 대화를 가볍게 이어갈 수 있습니다.
- **음성 입력:** 기본 음성 채널이 늘었고 자동으로 선택됩니다. Claude 로그인이 만료되면 Claude Code를 한 번 열어 갱신하라고 안내합니다.
- **개선 및 수정:** 설정 페이지가 열리고 닫힐 때 애니메이션이 적용됩니다. 업데이트 라벨이 더 이상 흔들리지 않고 로딩 표시가 위아래로 움직이지 않습니다.
