- **终端字体：** 默认终端字体换成 JetBrains Mono，字形更清晰紧凑。字体已内置在应用里，无需另外安装；在设置里选过其他字体的不受影响。

### Coffee CLI v4.0.0 · New Terminal Font

- **Terminal font:** The default terminal font is now JetBrains Mono, for crisper, more compact text. It ships inside the app, so there's nothing to install, and any font you picked in Settings stays as it is.

### Coffee CLI v4.0.0 · 全新終端字型

- **終端字型：** 預設終端字型換成 JetBrains Mono，字形更清晰緊湊。字型已內建在應用程式中，無需另外安裝；在設定裡選過其他字型的不受影響。
