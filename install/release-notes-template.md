### Coffee CLI v3.8.4 · 输入框工作树，自定义提示音

- **输入框工作树：** Claude Code、Codex、OpenCode 和 DeepSeek Harness 的新对话，发送前勾选「工作树」，就能在仓库的隔离副本和独立分支里工作。每轮结束后可以一键合并回项目；还没合并的工作不会被自动清理。
- **自定义提示音：** 在设置的声音页，可以给任务完成和等待权限分别选择 MP3 或 WAV 文件（20 MB 以内，最多播放 10 秒）。文件无法播放时自动回到默认提示音。
- **多智能体协作更强：** 可以选择主控的角色；worker 能在独立工作树里运行；运行中可以继续引导 worker；遇到临时的服务错误会自动重试；软件重启后，主控会知道哪些任务被中断。
- **输入框随内容增高：** 草稿变长时，输入框自动长高。
- **额度显示：** 识别更多中转站和模型厂商。
- **回到底部按钮：** 改为柔和的悬浮阴影，工作中会显示动画标记。
- **问题修复：** 打开历史对话会停在最新消息；滚动阅读时位置更稳；点输入框下方的按钮后，按回车仍能发送；Codex 运行中追加消息时不再丢失图片和技能；worker 的结果判定更准确；Claude Code 桌面标签的入口显示更准确。

### Coffee CLI v3.8.4 · Composer Worktrees, Custom Notification Sounds

- **Composer worktrees:** In a new Claude Code, Codex, OpenCode or DeepSeek Harness conversation, tick Worktree before sending to work in an isolated copy of the repository on its own branch. After each turn you can merge back in one click, and unmerged work is never cleaned up automatically.
- **Custom notification sounds:** In Settings > Sound, choose an MP3 or WAV file for task completion and for permission requests (up to 20 MB, plays for up to 10 seconds). If a file can't play, the default sound is used.
- **Stronger multi-agent work:** Choose the coordinator's role, run workers in their own worktrees, steer workers while they run, retry automatically after passing service errors, and let a coordinator know what a restart interrupted.
- **Composer grows with your draft:** The input box gets taller as your draft gets longer.
- **Usage display:** More relay services and model vendors are recognized.
- **Back-to-latest button:** It now has a soft floating shadow and shows the working mark during a turn.
- **Fixes:** History opens at the latest message; reading position holds steadier while scrolling; Enter still sends after clicking a button below the input; Codex keeps images and skills in messages added during a turn; worker outcomes are judged more accurately; Claude Code desktop tabs show their entrypoint correctly.

### Coffee CLI v3.8.4 · 入力欄のワークツリー、カスタム通知音

- **入力欄のワークツリー：** Claude Code、Codex、OpenCode、DeepSeek Harness の新しい会話で、送信前に「ワークツリー」をオンにすると、リポジトリの分離されたコピーと専用ブランチで作業できます。各ターンの後にワンクリックでマージでき、未マージの作業は自動で削除されません。

- **入力欄が内容に合わせて拡大：** 下書きが長くなると入力欄が高くなります。
- **使用量の表示：** より多くの中継サービスとモデルベンダーを認識します。
- **最新へ戻るボタン：** やわらかい影が付き、作業中はアニメーションを表示します。
- **修正：** 履歴は最新のメッセージで開きます。スクロール中の読書位置が安定しました。入力欄の下のボタンを押した後も Enter で送信できます。Codex の実行中に追加したメッセージで画像とスキルが失われなくなりました。ワーカーの結果判定がより正確になり、Claude Code デスクトップタブの入口表示も正確になりました。

### Coffee CLI v3.8.4 · 입력창 워크트리, 사용자 지정 알림음

- **입력창 워크트리:** Claude Code, Codex, OpenCode, DeepSeek Harness의 새 대화에서 보내기 전에 워크트리를 선택하면 저장소의 격리된 사본과 별도 브랜치에서 작업합니다. 턴이 끝날 때마다 한 번에 병합할 수 있고, 병합하지 않은 작업은 자동으로 삭제되지 않습니다.
- **사용자 지정 알림음:** 설정의 소리에서 작업 완료와 권한 대기에 각각 MP3 또는 WAV 파일을 선택할 수 있습니다(20 MB 이하, 최대 10초 재생). 재생할 수 없으면 기본 알림음을 사용합니다.
- **멀티 에이전트 강화:** 코디네이터 역할 선택, 워커의 별도 워크트리 실행, 실행 중인 워커 지시, 일시적인 서비스 오류 후 자동 재시도를 지원하며, 재시작으로 중단된 작업도 코디네이터에게 알려 줍니다.
- **내용에 맞춰 커지는 입력창:** 초안이 길어지면 입력창이 높아집니다.
- **사용량 표시:** 더 많은 중계 서비스와 모델 업체를 인식합니다.
- **맨 아래로 버튼:** 부드러운 그림자가 생겼고 작업 중에는 애니메이션을 표시합니다.
- **수정:** 기록은 최신 메시지에서 열립니다. 스크롤 중 읽던 위치가 더 안정적입니다. 입력창 아래 버튼을 누른 뒤에도 Enter로 보낼 수 있습니다. Codex 실행 중 추가한 메시지에서 이미지와 스킬이 사라지지 않습니다. 워커 결과 판정이 더 정확해졌고 Claude Code 데스크톱 탭의 진입점 표시도 정확해졌습니다.
