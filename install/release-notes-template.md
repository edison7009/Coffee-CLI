### Coffee CLI v3.7.7 · 協働セッションと操作性の改善

- **タスク連携：** 結果を自動回収し、重複した依頼を防止。子セッションを保持し、元の会話の再開、独立した会話への切り替え、グループ単位の終了に対応。
- **状態と動き：** タブの状態を緑・橙・青に統一し、作業中の履歴に回転アイコンを表示。新規作成時のみ子セッションをアニメーション表示。子の完了音を抑え、全体のまとめや承認要求は必要に応じて通知。
- **設定切り替え：** エージェント連携・コンピューター操作・ブラウザー操作の状態を保持してバックグラウンド更新し、表示のずれを軽減。
- **CLI とヒント：** Cursor のコマンド競合を修正し、起動と更新に同じランチャーを使用。更新ヒントを中央揃えにし、2 段のプレビューとログ見出しの区切りを改善。
- **安定性：** 協働ツール検索を多言語化し、元の詳細を保持。同時接続時のブラウザープロファイルのロック解放、会話復元、待機中の指示の取り消し、状態同期を改善。
