Coffee CLI 使用說明

從零開始，把 AI 程式設計工具用得順手

這份說明文件依照軟體裡的介面一頁一頁地講：每個按鈕在哪裡、按下去會發生什麼、有哪些要注意的地方。不需要程式基礎，跟著「五分鐘上手」走一遍，就能開始使用。

下載與安裝Windows / macOS / Linux，一行指令或一個安裝檔 五分鐘上手開啟軟體、選工具、選資料夾、送出第一則訊息 介面總覽先認識五個區域，後面就不會迷路 常見問題工具是灰色的？macOS 提示已損毀？

01認識 Coffee CLI

Claude Code、Codex、OpenCode 這類 AI 程式設計工具，原本都要在黑底白字的「終端機」裡使用。Coffee CLI 幫它們配了一個桌面：免費、開源，所有工具集中在一個視窗裡管理。

  • 一個視窗管理多個 AI：支援 20 多款 AI 工具，每個對話是一個分頁，隨時切換。
  • 兩種用法：Claude Code、Codex、OpenCode、Pi 可以用「桌面對話」介面，像聊天軟體一樣使用；也可以切回原汁原味的終端機。
  • 分割畫面同時看：最多 4 個對話並排顯示，誰在工作一眼就能看到。
  • 多個 AI 一起工作：讓 Claude Code 當主管，把任務分給其他 AI 同時進行。
  • 看清 AI 改了什麼：右側欄列出所有變更的檔案，逐行顯示新增和刪除。
  • 額度和餘額：在輸入框旁邊直接看到 Claude、Codex 的剩餘額度，或 DeepSeek 等服務的帳戶餘額。
先說明一點：Coffee CLI 本身不提供 AI 模型。你需要先在電腦上裝好想用的 AI 工具（例如 Claude Code），並依照那個工具自己的方式登入，Coffee CLI 會自動偵測到它。

02下載與安裝

兩種方式任選：在官網按下按鈕下載安裝檔，或者複製一行指令自動安裝。

方式一：下載安裝檔

開啟 coffeecli.com，點選你的系統對應的按鈕：

系統安裝檔說明
Windows.exe（另有 .msi）x64 電腦。按兩下安裝，缺少 WebView2 時安裝程式會自動補裝。
macOS.dmgApple 晶片和 Intel 晶片都支援。開啟後把 Coffee CLI 拖曳到「應用程式」。
Linux.deb / .rpmx64 和 arm64。Ubuntu / Debian 用 .deb，Fedora / openSUSE 等用 .rpm。

Intel Mac、ARM Linux 等其他版本，在官網下載按鈕下方的「更多版本」裡找。中國大陸使用者在簡體中文官網還能看到 百度網盤、夸克網盤、123雲盤 三個下載管道。

方式二：一行指令安裝

Windowsiwr -useb https://coffeecli.com/install.ps1 | iex
macOS / Linuxcurl -fsSL https://coffeecli.com/install.sh | sh
  • Windows：在「開始」按右鍵 → 選擇「終端機（系統管理員）」→ 貼上上面的指令，按 Enter。
  • macOS：開啟「終端機」App，貼上指令，按 Enter。腳本會自動安裝到「應用程式」。
  • Linux：在終端機裡執行，安裝 .deb / .rpm 時會要求輸入密碼。

已經是最新版時，腳本會直接告訴你，不會重複安裝。如果提示新版本剛發布、安裝檔還在上傳，等十來分鐘再執行一次即可。

macOS 提示「已損毀」或打不開？這是系統對網路下載 App 的攔截，不是檔案真的壞了。開啟「終端機」，執行下面這行，然後重新開啟 Coffee CLI：
xattr -cr '/Applications/Coffee CLI.app'

03五分鐘上手

以 Claude Code 為例，從開啟軟體到讓 AI 幫你工作。

  1. 裝好 AI 工具。Coffee CLI 只負責「管理」，AI 工具要自己安裝。例如 Claude Code，依照它官網的說明安裝並登入一次。
  2. 開啟 Coffee CLI。第一次開啟就會看到「啟動台」，上面有幾張工具卡片。已安裝的工具是亮的，沒裝的是灰色。
  3. 點 Claude Code 卡片，選一個資料夾。這個資料夾就是 AI 工作的地方，它能讀取、修改裡面的檔案。建議先新增一個空資料夾來練習。
  4. 在底部輸入框裡寫下需求，按 Enter 送出。例如「幫我做一個記帳的網頁」。AI 開始工作時，分頁上的小點會變成橘色。
  5. 處理 AI 的提問。AI 想修改檔案或執行指令時，可能會停下來問你。點 允許一次 讓它繼續，點 拒絕 不讓它做。
  6. 看結果。按 Alt+E 開啟右側欄，在 修改記錄 裡查看 AI 改了哪些檔案（資料夾需要是 Git 儲存庫）。
小技巧：左側的 會話記錄 會保存所有對話。下次開啟軟體，點一下就能接著上次聊。

05啟動台

新增對話時看到的頁面，用來選「哪個 AI」在「哪個資料夾」裡工作。

開啟啟動台

點左側欄頂部的 新建會話，或者標題列分頁列尾端的 +。如果已經有一個還沒選工具的空白分頁，會直接切過去，不會再開新的。

啟動一個 AI 工具

  1. 點工具卡片。
  2. 如果這個工具以前用過，卡片上會顯示上次的資料夾路徑，點一下就直接在那裡啟動。
  3. 第一次使用時卡片上寫著 選擇專案目錄：會跳出最近用過的資料夾清單，最下面是 開啟資料夾，可以選新的資料夾。
  4. 想換資料夾，點卡片右邊的資料夾按鈕。最近清單裡的每一項都可以點 × 刪掉。

OpenClaw 不需要選資料夾，點一下就啟動。之前用過的資料夾被刪除或移動後，會自動從清單裡移除。

桌面對話還是終端機？

Claude Code、Codex CLI、OpenCode、Pi 的卡片上有 Desktop / Terminal 切換：

  • Desktop（預設）：像聊天軟體一樣的介面，有按鈕可以點，適合新手。詳見 桌面對話模式。
  • Terminal：工具原本的命令列介面，適合熟悉終端機的使用者。詳見 終端機模式。

DeepSeek Harness 只有桌面模式，其餘工具都在終端機裡執行。你的選擇會被記住，從會話記錄恢復對話時也會用這個模式開啟。

支援哪些工具

Claude Code、Codex CLI、DeepSeek Harness、Cursor、Copilot CLI、Antigravity CLI、OpenClaw、Hermes Agent、OpenCode、Pi、Cline、Goose、Aider、Oh-My-Pi、Crush、Qwen Code、Kilo Code、Kiro、Kimi Code、CodeBuddy、Grok Build、MiMo Code、MiniMax Code、Muse Code，再加一個一般的 終端機。

啟動台最多同時擺 6 張卡片，第一次預設是 Claude Code、Codex CLI、OpenCode、Pi、DeepSeek Harness 和終端機。想換成別的工具，到 應用配置 → 常用。

工具是灰色的，點不動

表示 Coffee CLI 沒在電腦上找到這個工具。啟動台不負責安裝，你需要依照那個工具官網的說明自行安裝。裝好後切回 Coffee CLI 視窗，會自動重新偵測。

明明裝了還是灰的？把滑鼠移到啟動台底部的 識別不到? 上，會顯示原因和三種修復方法。常見原因是電腦的環境變數 PATH 被其他工具改壞了。

更新 AI 工具

工具有新版本時，卡片上會出現 更新 按鈕，滑鼠移上去能看到從哪個版本升到哪個版本。點選後顯示 更新中。軟體會依照你當初的安裝方式（npm、Homebrew 等）自動更新。

遠端終端機

點 終端機 卡片上的 遠端，可以連線到另一台電腦或伺服器：選 SSH 或 WebSocket，填入 伺服器位址、連接埠、使用者名稱、密碼，點 連線。最近 10 次連線會顯示成小標籤，點一下就能重新連線。

注意：遠端連線的密碼會以明文儲存在本機（~/.coffee-cli/credentials.json）。公用電腦上請不要儲存重要密碼。

06標題列

視窗最上面一條，主要是開啟中的對話分頁。

對話分頁

  • 每個開啟的對話是一個分頁，顯示工具圖示和專案資料夾名稱。點選切換，左右拖曳可以調整順序，點 × 關閉。
  • 還沒選工具的空白分頁叫 選擇工具。
  • 按兩下標題列空白處可以最大化或還原視窗，按住空白處拖曳可以移動視窗。

狀態點：一眼看出 AI 在做什麼

分頁右邊有一組小點，顏色表示 AI 的狀態：

顏色意思你需要做什麼
綠色閒置 / 已完成可以看結果或送出下一則訊息
橘色工作中等它做完就好
藍色等你操作切過去處理權限確認或回答它的問題

Linux 上只顯示一個不動的彩色圓點，沒有動畫。任務完成和等待你操作時還會響提示音，可以在 設定 → 通用 裡更換或關閉。

其他按鈕

  • 更新日誌：查看目前版本更新了什麼。軟體升級後第一次開啟會自動跳出一次。
  • 三個面板開關：左側欄、輸入框、右側欄，見 介面總覽。
  • 設定：平時在左側欄底部；左側欄隱藏時，會出現在標題列上。
  • Windows / Linux 的最小化、最大化、關閉按鈕在最右邊；macOS 用系統內建的紅黃綠按鈕。

07左側欄

管理所有對話和專案檔案。頂部有 新建會話 和兩個檢視切換：會話記錄、工作區。

會話記錄：所有歷史對話

  • 接著聊：點任意一則。對話已經開著會直接切過去；沒開的話會新開一個分頁，在原本的資料夾裡繼續。
  • 找對話：點 搜尋，可以依標題、工具名稱、專案路徑尋找。用 ↑↓ 選擇，Enter 開啟，Esc 關閉。
  • 換個排列方式：右上角漏斗圖示是 顯示方式：
    • 會話列表：看全部，或只看某一個工具的對話。
    • 專案分類：依資料夾分組。可選 全部目錄 或 僅已新增，每組先顯示 5 則，點 顯示更多 展開。
    • 應用圖示：選擇顯示或不顯示工具圖示。
  • 正在執行的對話會排在最上面，接著是置頂的對話。滑鼠停留在上面能看到專案名稱、時間和訊息則數。

對話卡片上的小標記

標記意思
轉圈工作中
藍色標籤等待操作：AI 在等你確認
藍色小圓點新回覆未讀
PR 圖示這個對話的分支有 GitHub PR。綠色 = 待合併，紫色 = 已合併，紅色 = 已關閉；角落的 ✓ / × / · 分別是檢查通過、失敗、執行中

右鍵選單

  • 在分割畫面中開啟：在目前對話右邊以分割畫面顯示，見 分割畫面。
  • 置頂 / 取消置頂、重新命名（按 Enter 儲存，Esc 取消）。
  • 複製會話ID、複製恢復命令：想在別的終端機裡接續這個對話時使用。
  • 複製完整路徑、在檔案總管中顯示：找到這個對話的記錄檔案。
  • 刪除：滑鼠停留時出現的垃圾桶按鈕效果一樣。
放心刪：「刪除」只是把對話從清單裡隱藏，不會刪掉 AI 工具自己儲存的記錄檔案。如果這個對話正開著，它的分頁會一起關閉。

工作區：專案檔案

  • 顯示目前對話所在資料夾裡的檔案，檔案有變化會自動重新整理。
  • 有未提交變更的檔案後面會顯示 +N -M（新增和刪除的行數）。
  • 點放大鏡可以 篩選檔案和資料夾…（只篩選第一層）。
  • 右鍵點檔案：開啟（用系統預設程式）、複製絕對路徑、複製相對路徑、複製為 @reference、剪下 / 複製 / 貼上、重新命名、刪除、在檔案總管中顯示。
讓 AI 看某個檔案：右鍵點檔案 → 複製為 @reference，貼到輸入框裡，AI 就知道你說的是哪個檔案。

底部按鈕

  • Coffee Agent 和訊息渠道狀態（例如「微信 · 未連線」），見 Coffee Agent。
  • 下載圖示：Coffee CLI 有新版本時才出現，見 更新與解除安裝。
  • 齒輪：開啟 設定。

左側欄頂部還有 應用配置、使用統計、自動化 三個入口，分別見後面的「功能頁面」。

08對話：桌面對話模式

Claude Code、Codex、OpenCode、Pi、DeepSeek Harness 可以用這種像聊天軟體一樣的介面。不用記指令，大部分操作按按鈕就行。

看懂 AI 的回覆

  • 思考過程：AI 思考問題時顯示 正在思考中…，想完變成「思考了 X 秒」，點一下能展開看它怎麼想的。Claude 還可以按 Ctrl+O 一次展開或收合全部思考。
  • 修改檔案卡片：顯示刪了幾行、加了幾行，並左右對照顯示變更。點檔案路徑會在檔案總管裡找到它。
  • 執行指令卡片：分成 輸入（執行了什麼指令）和 輸出（指令的結果）兩部分。
  • 每輪小結：每次回覆結束後，下面有一行「耗時 · Token 數 · 大約花了多少錢」。
  • 複製：每則訊息旁邊都有 複製訊息 按鈕。

AI 停下來問你時

AI 想修改檔案、執行指令，或者需要你做決定時，會跳出一張卡片，分頁上的狀態點同時變成藍色：

  • 權限確認：例如「允許 Bash 嗎？」。點 允許一次 或 拒絕。Codex 還有 本次工作階段允許，OpenCode 還有 一律允許。
  • 計畫確認（Claude）：準備實作這個計畫嗎？ 看完計畫再決定要不要開始。
  • 提問：選一個選項，或在輸入框裡寫補充說明，再點 提交。可以用數字鍵 1–9 快速選擇。

權限模式：AI 能自己做多少事

輸入框底部的權限按鈕決定 AI 動手前要不要問你：

工具可選檔位（從謹慎到放手）
Claude Code手動（編輯和執行指令前都問）→ 計畫（先提出方案再動手）→ 自動編輯（改檔案不問，其他會問）→ 自動（部分模型才有）→ 略過權限確認
Codex唯讀 → 工作區 → 完整存取；另有 計畫模式 開關
DeepSeek Harness工作區內修改 → 完全權限
OpenCode沒有權限按鈕，可切換 智慧體
新手建議：先用預設檔位，讓 AI 每次動手前都問你。熟悉之後再放寬權限。

換模型和思考強度

  • 模型：點輸入框底部的模型名稱，從選單裡更換。每個模型後面標著價格（輸入 / 輸出，每百萬 token）。
  • 思考強度：一根滑桿，從 更快 到 更深入，檔位有 低 / 中 / 高 / 超高 / 最高。關閉選單後才生效，按 Esc 放棄修改。

上下文圓環：AI 還能記住多少

輸入框右下角的小圓環表示這個對話用掉了多少「記憶空間」。超過 75% 會變色提醒，超過 90% 變成紅色。點開能看到具體用量。

快滿時，可以點裡面的 開新對話繼續：開一個新對話，需要時讓它回頭查閱舊記錄，你寫了一半的草稿也會保留，不會自動送出。

「/」指令選單

在輸入框裡打 /，或點 / 按鈕，會跳出這個工具支援的指令，例如 /model（換模型）、/compact（壓縮對話）、/new（新對話）。用 ↑↓ 選擇，Enter 執行。

工作樹：在副本裡放心嘗試

輸入框底部資料夾名稱旁邊的 工作樹 核取方塊。勾選後，AI 會在專案的一份獨立副本（單獨的分支）裡工作，不會動到你原本的檔案。

  1. 送出第一則訊息之前勾選。對話開始後就不能改了。
  2. AI 做完後，會出現 合併到 … 按鈕。點它把變更合併回原本的專案。
  3. 如果和原專案衝突，會自動撤銷這次合併，原專案不受影響。

專案資料夾需要是 Git 儲存庫，並且至少有一次提交。

其他貼心功能

  • 停止：按 Esc 或點方塊按鈕，隨時讓 AI 停下。
  • 快速定位：對話變長後，右側會出現一列小圓點，每個代表你的一次提問，點選就能跳過去。
  • 回到最新：往上捲動後，右下角的向下箭頭可以一鍵回到最新訊息。
  • 提示詞建議（Claude）：輸入框為空時，灰字會猜你下一句想說什麼，按 Tab 採用。
  • 閒置很久後回來（Claude、Codex）：會問你要 完整恢復 還是 開新對話繼續（推薦）。舊對話很長時選後者更快也更省。
  • 載入更早的訊息（Claude）：恢復很長的舊對話時，在頂部點這個按鈕載入更早的內容。

09對話：終端機模式

直接顯示 AI 工具原本的命令列介面。除了 Claude Code、Codex、OpenCode、Pi、DeepSeek Harness 之外，其他工具都用這種模式。

想做什麼怎麼做
複製選取文字，按 Ctrl/⌘+C。沒有選取文字時，Ctrl+C 是中斷目前程式
貼上Ctrl/⌘+V。Linux 也可以用 Ctrl+Shift+C / V
傳圖片給 AI直接貼上截圖，會自動存成檔案並貼上它的路徑
引用檔案把檔案拖曳到終端機，會插入檔案路徑
開啟連結點網址用瀏覽器開啟；點本機路徑會在檔案總管裡顯示它（不會執行）
翻看歷史可往回捲動最近 5000 行，捲上去後有「返回最新訊息」按鈕

右鍵選單有複製、貼上、全選；在連結或路徑上按右鍵，還會多出開啟和複製連結的選項。終端機字型和文字顏色在 設定 → 終端機 裡修改。

不習慣在終端機裡打字？按 Alt+W 開啟底部輸入框，在裡面寫好、可以貼圖片，再一次傳送給終端機。

10輸入框

對話區最下面寫需求的地方。桌面對話模式下一直顯示，終端機模式下用 Alt+W 開啟或隱藏。

送出和換行

  • 預設 Enter 送出，Shift+Enter 換行。習慣相反的，到 設定 → 通用 → 發送訊息 改成 Ctrl/⌘+Enter 送出。
  • Alt+↑ / Alt+↓：叫出以前送出過的內容。
  • 拖曳輸入框上緣可以調整高度。輸入框左下角顯示訊息會送到哪個工具、哪個資料夾。
  • AI 工作時若輸入框是空的，送出按鈕會變成方塊 停止。桌面對話模式下，AI 工作時也可以繼續傳訊息補充要求。

傳送圖片和檔案

  • 截圖後直接貼上（Ctrl/⌘+V）：輸入框上方會出現縮圖，點 × 可以移除。
  • 把檔案拖曳進來：會插入檔案路徑。
  • 點迴紋針 新增附件：選擇檔案。

儲存到預輸入

輸入框裡有字時，上方會出現 儲存到預輸入。想法還沒想好、或者 AI 正忙，先存起來，之後在 右側欄 → 預輸入 裡點一下就能放回輸入框。旁邊的垃圾桶是 清空。

語音輸入

  1. 點送出按鈕左邊的麥克風，開始說話，旁邊會出現波形。
  2. 說完再點一下，文字會寫進輸入框，確認後再送出。

語音輸入借用你已登入的帳號（例如 Claude Code、ChatGPT、豆包）來辨識。看不到麥克風按鈕？到 設定 → 語音輸入 開啟開關並掃描語音管道。macOS 也可以用系統內建的語音辨識，但要先在「系統設定 → 鍵盤 → 聽寫」中開啟聽寫。

方案額度條

輸入框底部右側顯示帳號還剩多少額度：Claude、Codex 顯示 5 小時 / 每週額度的剩餘百分比和重設倒數；DeepSeek、Kimi、OpenRouter 等依用量付費的服務顯示 餘額 或 已用。剩餘不足 30% 會變色提醒，點一下可以重新整理。

11分割畫面

同時並排看最多 4 個對話，適合幾個 AI 一起工作時盯進度。

開啟分割畫面的兩種方法

  • 拖曳進來：在左側 會話記錄 裡按住一個對話，拖曳到中間對話區。靠近哪一邊，就在哪一側顯示 分割畫面 的預覽，放開即完成。拖曳時按 Esc 取消。
  • 右鍵選單：在對話上按右鍵 → 在分割畫面中開啟，它會出現在目前對話的右側。

調整和關閉

  • 拖曳窗格之間的分隔線調整大小；按兩下分隔線恢復成各占一半。
  • 點哪個窗格，哪個就是目前對話，輸入框的訊息會送到這裡。
  • 每個窗格角落有編號小標，滑鼠移上去變成 ×，點它 關閉分割畫面。
  • 已經有 4 個窗格時，會提示 最多同時顯示四個對話。

12右側欄

用 Alt+E 或標題列右邊的圖示開啟。有三個分頁：預輸入、修改記錄、檔案比較。

預輸入：先把想法存起來

  • 新增：在輸入框裡寫好，點上方的 儲存到預輸入，就變成一張便利貼。
  • 使用：點便利貼內文，內容會附加到目前對話的輸入框裡（不會直接送出），確認後自己送出。
  • 整理：上下拖曳調整順序；滑鼠移上去，右邊會出現垃圾桶可以刪除。
  • 便利貼不能直接改字。想修改的話，先放回輸入框，改好後重新儲存。

如果設定了 自動化，預輸入頁頂部會顯示 正在自動化，點卡片右邊的 ▶ 可以把這項任務立刻傳給目前對話。

修改記錄：AI 改了哪些檔案

列出目前對話所在專案裡改過的檔案。這一頁只能看，不能修改。

  • 頂部顯示目前分支名稱；如果有 GitHub PR，會顯示 PR 編號、狀態和檢查結果，點選後在瀏覽器裡開啟。
  • 檢視範圍：全部修改 / 未提交 / 本次對話提交，旁邊統計檔案數和增刪行數。
  • 用 篩選檔案… 依路徑尋找。點檔案名稱開啟 檔案比較，按右鍵可以複製路徑。
  • 大約每 8 秒自動重新整理一次。
看不到修改記錄？需要滿足三個條件：電腦裝了 Git；專案資料夾是一個 Git 儲存庫；已經選好了工作區。不滿足時會顯示相應提示，例如 此目錄暫無 Git 修改記錄。

檔案比較：逐行看變更

  • 綠色 + 是新增的行，紅色 − 是刪除的行，程式碼會依語法上色。
  • 用 ‹ › 在變更的檔案之間切換。連續沒改的行會摺疊，點一下展開。
  • 右上角的按鈕可以把比較放大成中間的一個分頁，看得更清楚；按 Esc 關閉。
  • Markdown（.md）檔案會直接顯示排版後的內容。檔案太大時只顯示變更行數。

13應用配置

左側欄的 應用配置，集中管理所有 AI 工具。頂部有 6 個分頁。

常用：啟動台擺哪些工具

點工具卡片開啟或關閉，最多選 6 個，會顯示在啟動台上。帶齒輪的工具可以點齒輪開啟啟動設定：

  • 預設啟動命令：Claude Code、Codex CLI、OpenCode 可以一鍵選擇啟動時的權限檔位，例如 Claude 的 計畫、自動編輯、略過權限確認。
  • 啟動命令、額外參數（每行一個）、啟動目錄、歷史對話目錄：給熟悉命令列的使用者自訂。
  • 改亂了點 重設，改好點 儲存。

主記憶：給 AI 的長期說明

直接編輯每個工具的全域說明檔案，例如 Claude Code 的 ~/.claude/CLAUDE.md、Codex 的 ~/.codex/AGENTS.md。寫在這裡的話（例如「請用繁體中文回答」「程式碼註解寫詳細一點」），AI 每次對話都會遵守。改完點 儲存 或按 Ctrl/⌘+S。

多智慧體編排

選擇哪些 AI 可以當助手，以及主視窗的角色，詳見下一節 多智慧體編排。

技能：幫 AI 裝新本領

  1. 在 探索 分頁裡 搜尋技能。
  2. 點 安裝，再選要裝到哪個工具。
  3. 每個工具的分頁列出已安裝的技能，透過 Coffee CLI 安裝的可以 更新 或 移除。

電腦控制 與 瀏覽器控制

讓 AI 能看螢幕、點滑鼠、打字（電腦控制），或者操作瀏覽器開啟網頁、點按鈕（瀏覽器控制）。用法都是：先點 檢測（瀏覽器控制第一次要先點安裝），再開啟要使用的工具的開關。

  • 電腦控制目前只支援 Windows。
  • 瀏覽器控制支援 Windows、macOS、Linux，需要先裝好 Chrome 瀏覽器。
  • 開啟後，輸入框底部會顯示對應標籤。

「主記憶」及之後的分頁，只列出在「常用」裡開啟的工具。

14多智慧體編排

讓 Claude Code 當「主管」：它自己判斷哪些工作交給其他 AI，每個助手開成一個子分頁同時工作，最後由它檢查、彙整結果給你。

開啟

  1. 開啟 應用配置 → 多智慧體編排。
  2. 勾選可以當助手的工具：Claude Code、Codex、OpenCode、DeepSeek Harness、Pi。沒裝的會顯示 未安裝。
  3. 在 主視窗角色 裡三選一（對之後新開的主視窗生效）：
    • 自主決策：主視窗自己判斷哪些自己做、哪些分派出去。
    • 專案經理：只拆分和分派任務、審核結果，自己不修改檔案。
    • 主廚：核心部分親自做，周邊雜事交給助手。

使用

  1. 新增一個 Claude Code 對話（桌面或終端機模式都可以）。
  2. 輸入框底部會顯示 優先協作：自主決策，點開可以指定優先使用某個助手。
  3. 像平常一樣提出需求。需要時，對話裡會出現「派發協作任務」「等待協作結果」等卡片，助手以子分頁的形式出現在標題列。

看進度、管理助手

  • 在 會話記錄 裡，主對話下方會列出它的助手：轉圈表示正在工作，圓點表示等你操作。點一下切到那個助手。
  • 助手跳出權限確認時，需要切到它的分頁裡處理。
  • 在助手上按右鍵：開啟原會話、轉為獨立會話、刪除。刪除還在執行的助手會先請你確認。
  • 關閉還有助手在執行的主對話時，可以選 保留子會話 或 結束整組。
變更不打架：在 Git 儲存庫裡，主視窗可以讓每個助手在獨立的工作樹（單獨的分支）上工作，最後由主視窗統一合併。

15自動化

到了設定的時間，自動開啟一個對話，把你寫好的內容傳給 AI。適合每天早上自動總結、定時檢查之類的重複工作。

新增一項自動化

  1. 點左側欄的 自動化，再點 + 新增自動化。
  2. 填入 名稱（可不填）和 要傳送的內容。
  3. 在 應用 裡選 Claude Code、Codex、DeepSeek Harness、OpenCode 或 Pi。
  4. 選擇 工作目錄：從用過的資料夾裡挑，或點 其他目錄…。
  5. 設定 時間：每天 / 工作日 / 每週 / 每隔（最少 5 分鐘）/ 一次。
  6. 點 儲存。

每項自動化都可以 立即執行、編輯、刪除，用開關暫停。清單裡顯示下次執行時間和上次結果，點 查看會話 可以看那次執行的對話。

兩個一定要知道的重點：
  • 先給 AI 開啟自動執行權限。到時間執行時沒人在旁邊點「允許」，請先在對應工具裡開啟，例如 Claude 的 略過權限確認、Codex 的 完整存取，否則任務會一直停在等待核准。
  • Coffee CLI 要保持開啟。軟體關閉期間不會執行；錯過的任務會在下次開啟軟體後補跑一次。

16使用統計

左側欄的 使用統計，看你和 AI 一起工作了多少。

  • 熱度圖：近一年每天的訊息數，顏色越深聊得越多。
  • 篩選：依 今天 / 近 7 天 / 近 30 天、依工具、依專案查看。點 同步 手動重新整理。
  • 資料卡片：Token 總量、對話數、提問次數、活躍天數、快取命中率。
  • 圖表：Token 趨勢、各模型用量占比和明細表。

Token 統計目前支援 Claude Code、Codex CLI、OpenCode、Pi、DeepSeek Harness。資料都來自你電腦上的本機記錄，不會上傳。

17設定

點左側欄底部的齒輪，或按 Ctrl+,（macOS 是 ⌘+,）。按 Esc 或點 返回 關閉。

通用

  • 介面縮放：整體放大縮小（70%–150%），字太小看不清楚就調這裡。
  • 輸入框的「儲存到預輸入」按鈕：顯示或隱藏這個按鈕。
  • 發送訊息：選擇按 Enter 送出還是 Ctrl/⌘+Enter 送出。
  • 開關快捷鍵：左側欄 / 輸入框 / 右側欄的快速鍵，可選 Alt+QWE、Ctrl+QWE、Alt+123、Ctrl+123。
  • 任務完成提示音、等待權限提示音：可以試聽、關閉，或點 更換 用自己的 MP3 / WAV（20 MB 以內）。

外觀

  • 配色：24 套配色，每套都有 明亮、夜晚、跟隨主題（跟隨系統深色 / 淺色）三種模式。
  • 形態：10 種介面風格，例如柔和、銳角、玻璃、毛玻璃、字元流。「毛玻璃」會讓視窗後面的桌面透出來變模糊（Linux 需要 KDE 桌面）。
  • 圖示風格：資料夾和檔案圖示的樣式。
  • 桌布：用自己的圖片或影片當背景，可以調整 透明度。

終端機

  • 文字顏色：終端機文字的顏色。
  • 字型：預設是內建的 JetBrains Mono，也可以搜尋選擇電腦上安裝的字型。
  • 預設終端：Windows 可選 PowerShell、Git Bash、命令提示字元等；macOS / Linux 可選 zsh、bash 等。不確定就保持 Auto。

語音輸入

  • 總開關、選擇 麥克風、測試麥克風。
  • 語音管道：點 掃描語音管道，找出電腦上已登入、能用來辨識語音的帳號。標示「即時轉寫」的邊說邊出字，標示「錄完轉寫」的說完才出字。
  • 提示「登入已過期」時，依提示開啟對應工具傳一則訊息即可續期。

語言

介面支援 11 種語言：English、简体中文、繁體中文、日本語、한국어、Español、Français、Deutsch、Português、Русский、Tiếng Việt，點一下立即切換。

BUG / 建議

遇到問題或有想法，從這裡提交到 GitHub。簡體中文介面還提供中國大陸可存取的 GitCode 入口。

18Coffee Agent

透過微信或 Telegram 與 Coffee Agent 對話：讀取終端機、安排任務，在手機上繼續接手電腦上的工作。

  1. 開啟 設定 → Coffee Agent，先讀一遍頂部的「使用說明」。
  2. 在 Coffee Agent 模型設定 裡選服務類型（OpenAI 相容 / Anthropic 相容），填入服務位址、模型 ID、API 金鑰。
  3. 在 訊息渠道 裡連線：微信掃描 QR Code；Telegram 貼上 BotFather 給的 Token，再在 10 分鐘內傳送配對碼。
  4. 連線成功後，左側欄底部會顯示「微信已連線」，在手機上傳訊息給它即可。

工作方式 裡有幾個開關，其中 哨兵模式 開啟後，Claude Code、Codex 等工具每輪工作結束時，Coffee Agent 會主動把結果傳到你的微信或 Telegram，不用你先問。需要保持 Coffee CLI 執行中。

20更新與解除安裝

更新 Coffee CLI

有新版本時，左側欄底部齒輪旁會出現一個下載圖示。點它後會自動挑一個速度快的下載來源，下載到「下載」資料夾並驗證，然後：

  • Windows：自動開啟安裝精靈，依提示完成即可。
  • macOS：自動開啟 DMG，把 Coffee CLI 拖曳到「應用程式」取代舊版。
  • Linux：開啟「下載」資料夾，按兩下 .deb 或 .rpm 安裝。

下載失敗時會自動開啟官網，手動下載即可。也可以重新執行 安裝指令，它會裝上最新版。

解除安裝

  • Windows：在「設定 → 應用程式」裡解除安裝 Coffee CLI。解除安裝畫面可以勾選是否同時刪除應用程式資料。
  • macOS：把「應用程式」裡的 Coffee CLI 拖曳到垃圾桶。
  • Linux：執行 sudo apt remove coffee-cli 或 sudo dnf remove coffee-cli。

解除安裝 Coffee CLI 不會刪除你安裝的 AI 工具，也不會刪除它們的對話記錄。

21常見問題

啟動台上的工具是灰色的？

表示沒找到這個工具。先確認已經依照工具官網的說明裝好，再切回 Coffee CLI 視窗讓它重新偵測。裝了還是灰的，看啟動台底部的 識別不到?。

macOS 提示「已損毀，無法開啟」？

在「終端機」裡執行 xattr -cr '/Applications/Coffee CLI.app'，然後重新開啟。詳見 下載與安裝。

需要付費嗎？

Coffee CLI 免費、開源。AI 工具本身的費用（例如 Claude、Codex 的訂閱或 API 費用）依各家的規則收取，與 Coffee CLI 無關。

右側「修改記錄」什麼都沒有？

需要電腦裝了 Git，並且專案資料夾是 Git 儲存庫。不熟悉 Git 的話，可以直接請 AI 幫你：「幫我把這個資料夾初始化成 Git 儲存庫」。

自動化時間到了卻沒動靜？

最常見的原因是任務停在「等待核准」：請在對應工具裡開啟自動執行權限。另外，Coffee CLI 需要保持開啟。

看不到麥克風按鈕 / 語音輸入失敗？

到 設定 → 語音輸入：開啟開關，點 掃描語音管道，確認至少有一個可用的管道。macOS 使用系統語音時，要先在「系統設定 → 鍵盤 → 聽寫」中開啟聽寫。

刪除對話會不會把聊天記錄刪掉？

不會。刪除只是從清單裡隱藏，AI 工具自己儲存的記錄檔案還在。

AI 把我的檔案改壞了怎麼辦？

養成兩個習慣：一是在 Git 儲存庫裡工作，隨時能在 修改記錄 裡看到改了什麼、需要時可以復原；二是對沒把握的任務勾選 工作樹，讓 AI 在副本裡修改，滿意了再合併。

還有其他問題？

到 GitHub 或 GitCode（中國大陸） 提問，或寄信到 hi@coffeecli.com。
