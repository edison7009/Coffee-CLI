Coffee CLI Docs

Get comfortable with AI coding tools, starting from zero

This guide walks through the app one screen at a time: where each button is, what happens when you click it, and what to watch out for. No coding background needed. Follow the "Five-minute start" once and you're ready to go.

01Meet Coffee CLI

AI coding tools like Claude Code, Codex and OpenCode normally live in the "terminal" — a window of plain text on a dark background. Coffee CLI gives them a desktop: it's free, open source, and puts all your tools in one window.

  • One window for many AIs: works with more than 20 AI tools. Each conversation is a tab you can switch to at any time.
  • Two ways to work: Claude Code, Codex, OpenCode and Pi can run in the "Desktop" view, which feels like a chat app. You can also switch back to the original terminal.
  • Watch several at once: show up to 4 conversations side by side and see at a glance which one is busy.
  • Several AIs working together: let Claude Code act as the lead and hand tasks to other AIs that work in parallel.
  • See exactly what the AI changed: the right panel lists every changed file and shows added and removed lines one by one.
  • Quota and balance: see your remaining Claude or Codex quota, or your account balance with services like DeepSeek, right next to the input box.
One thing first: Coffee CLI doesn't come with an AI model. Install the AI tool you want to use (for example Claude Code) and sign in the way that tool tells you to. Coffee CLI will find it automatically.

02Download and install

Pick either way: download an installer from the website, or copy one command that installs it for you.

Option 1: Download an installer

Go to coffeecli.com and click the button for your system:

SystemInstallerNotes
Windows.exe (also .msi)For x64 PCs. Double-click to install. If WebView2 is missing, the installer adds it for you.
macOS.dmgWorks on both Apple silicon and Intel Macs. Open it and drag Coffee CLI into Applications.
Linux.deb / .rpmx64 and arm64. Use .deb on Ubuntu / Debian, and .rpm on Fedora, openSUSE and similar.

For other builds, such as Intel Mac or ARM Linux, look under "More versions" below the download button on the website.

Option 2: Install with one command

Windowsiwr -useb https://coffeecli.com/install.ps1 | iex
macOS / Linuxcurl -fsSL https://coffeecli.com/install.sh | sh
  • Windows: right-click the Start menu → choose "Terminal (Admin)" → paste the command above and press Enter.
  • macOS: open the Terminal app, paste the command and press Enter. The script installs the app into Applications for you.
  • Linux: run it in a terminal. You'll be asked for your password when the .deb / .rpm is installed.

If you already have the latest version, the script tells you so and doesn't install it again. If it says a new version was just released and the installers are still uploading, wait about ten minutes and run it again.

macOS says the app "is damaged" or won't open? This is macOS blocking an app downloaded from the internet — the file isn't actually broken. Open Terminal, run the line below, then open Coffee CLI again:
xattr -cr '/Applications/Coffee CLI.app'

03Five-minute start

Using Claude Code as the example: from opening the app to getting the AI to work for you.

  1. Install an AI tool. Coffee CLI only manages the tools; you install them yourself. For Claude Code, follow the instructions on its website to install it and sign in once.
  2. Open Coffee CLI. The first time, you'll see the launchpad with a few tool cards. Installed tools are lit up; tools you don't have are gray.
  3. Click the Claude Code card and pick a folder. This folder is where the AI works — it can read and change the files inside. For practice, create a new empty folder first.
  4. Type what you want in the input box at the bottom and press Enter. For example, "Make me a web page for tracking expenses." While the AI works, the small dot on the tab turns orange.
  5. Answer the AI's questions. When the AI wants to change a file or run a command, it may stop and ask you. Click Allow once to let it continue, or Reject to stop it.
  6. Check the result. Press Alt+E to open the right panel and look at Changes to see which files the AI changed (the folder needs to be a Git repository).
Tip: Sessions on the left keeps every conversation. Next time you open the app, click one to pick up where you left off.

05Launchpad

The page you see when you start a new session. Here you choose which AI works in which folder.

Open the launchpad

Click New session at the top of the sidebar, or the + at the end of the tab strip in the title bar. If you already have an empty tab with no tool chosen, the app switches to it instead of opening another one.

Start an AI tool

  1. Click a tool card.
  2. If you've used this tool before, the card shows the last folder you used. Click it to start there right away.
  3. The first time, the card says Choose a project folder. A list of recent folders pops up, with Open Folder at the bottom for picking a new one.
  4. To change folders, click the folder button on the right of the card. You can remove any item from the recent list with ×.

OpenClaw doesn't need a folder — one click starts it. If a folder you used before is deleted or moved, it disappears from the list automatically.

Desktop or Terminal?

The cards for Claude Code, Codex CLI, OpenCode and Pi have a Desktop / Terminal switch:

  • Desktop (default): a chat-app style view with buttons to click. Good for beginners. See Desktop mode.
  • Terminal: the tool's original command-line view, for people comfortable with the terminal. See Terminal mode.

DeepSeek Harness only has Desktop mode; all other tools run in the terminal. Your choice is remembered, and conversations you reopen from Sessions open in the same mode.

Supported tools

Claude Code, Codex CLI, DeepSeek Harness, Cursor, Copilot CLI, Antigravity CLI, OpenClaw, Hermes Agent, OpenCode, Pi, Cline, Goose, Aider, Oh-My-Pi, Crush, Qwen Code, Kilo Code, Kiro, Kimi Code, CodeBuddy, Grok Build, MiMo Code, MiniMax Code, Muse Code, plus a plain Terminal.

The launchpad shows up to 6 cards at a time. By default they are Claude Code, Codex CLI, OpenCode, Pi, DeepSeek Harness and Terminal. To swap in other tools, go to Agent configuration → Favorites.

A tool is gray and won't click

This means Coffee CLI couldn't find that tool on your computer. The launchpad doesn't install tools — install it yourself by following the tool's website. Once it's installed, switch back to the Coffee CLI window and it checks again automatically.

Installed but still gray? Hover over Can't detect? at the bottom of the launchpad to see why and three ways to fix it. A common cause is that another tool broke your computer's PATH environment variable.

Update AI tools

When a tool has a new version, an Update button appears on its card. Hover over it to see which version it will update from and to. After you click it, it shows Updating. The app updates the tool the same way you originally installed it (npm, Homebrew and so on).

Remote terminal

Click Remote on the Terminal card to connect to another computer or server: choose SSH or WebSocket, fill in Host, port, Username and Password, then click Connect. Your last 10 connections appear as small chips — click one to reconnect.

Note: passwords for remote connections are saved as plain text on this computer (~/.coffee-cli/credentials.json). Don't save important passwords on a shared computer.

06Title bar

The strip at the very top of the window, mostly taken up by your open session tabs.

Session tabs

  • Each open conversation is a tab showing the tool's icon and the project folder name. Click to switch, drag left or right to reorder, and click × to close.
  • An empty tab with no tool chosen yet is called Select Tool.
  • Double-click an empty part of the title bar to maximize or restore the window. Drag an empty part to move the window.

Status dots: see what the AI is doing at a glance

A small group of dots on the right of each tab shows the AI's status by color:

ColorMeaningWhat you should do
GreenIdle / doneCheck the result or send your next message
OrangeWorkingJust wait for it to finish
BlueWaiting for youSwitch to it and handle the permission prompt or answer its question

On Linux you see a single still colored dot with no animation. A sound also plays when a task finishes and when the AI is waiting for you. You can change or turn off these sounds in Settings → General.

Other buttons

  • Changelog: see what's new in the current version. It opens once automatically the first time you start the app after an update.
  • Three panel toggles: sidebar, input box and right panel. See Window overview.
  • Settings: normally at the bottom of the sidebar. When the sidebar is hidden, it moves to the title bar.
  • On Windows / Linux, the minimize, maximize and close buttons are at the far right. macOS uses its own red, yellow and green buttons.

07Sidebar

Manages all your conversations and project files. At the top are New session and two views: Sessions and Workspace.

Sessions: every past conversation

  • Keep chatting: click any item. If the conversation is already open, the app switches to it. If not, it opens in a new tab and continues in the original folder.
  • Find a conversation: click Search to look up conversations by title, tool name or project path. Use ↑↓ to choose, Enter to open and Esc to close.
  • Change how the list looks: the funnel icon in the top-right corner is View:
    • Sessions: show everything, or only one tool's conversations.
    • Projects: group by folder. Choose All folders or Added folders only. Each group shows 5 items at first; click Show more to see the rest.
    • App icons: show or hide tool icons.
  • Running conversations are listed first, followed by pinned ones. Hover over a conversation to see its project name, time and number of messages.

Small badges on conversation cards

BadgeMeaning
SpinnerWorking
Blue labelAwaiting action: the AI is waiting for you to confirm
Small blue dotUnread reply
PR iconThis conversation's branch has a GitHub PR. Green = Open, purple = Merged, red = Closed. The ✓ / × / · in the corner means checks passed, failed or are still running

Right-click menu

  • Open in split view: shows it in a split to the right of the current conversation. See Split view.
  • Pin / Unpin, Rename (press Enter to save, Esc to cancel).
  • Copy session ID, Copy resume command: use these to continue the conversation in another terminal.
  • Copy full path, Reveal in File Explorer: find this conversation's log file.
  • Delete: does the same thing as the trash button that appears when you hover.
Deleting is safe: "Delete" only hides the conversation from the list. It doesn't remove the log files the AI tool saved. If the conversation is open, its tab closes too.

Workspace: project files

  • Shows the files in the current conversation's folder and refreshes automatically when files change.
  • Files with uncommitted changes show +N -M (lines added and removed).
  • Click the magnifying glass to Filter files and folders… (top level only).
  • Right-click a file: Open (with the system's default app), Copy Absolute Path, Copy Relative Path, Copy as @reference, cut / copy / paste, rename, delete, Reveal in File Explorer.
Point the AI at a file: right-click the file → Copy as @reference, then paste it into the input box. The AI will know exactly which file you mean.

Bottom buttons

  • Coffee Agent and its messaging channel status (for example "WeChat · Disconnected"). See Coffee Agent.
  • Download icon: appears only when a new version of Coffee CLI is available. See Update and uninstall.
  • Gear: opens Settings.

The top of the sidebar also has three entries — Agent configuration, Usage statistics and Automations — covered under "Feature pages" below.

08Sessions: Desktop mode

Claude Code, Codex, OpenCode, Pi and DeepSeek Harness can use this chat-app style view. No commands to remember — most things are just a button click.

Reading the AI's replies

  • Thinking: while the AI thinks, you see Thinking…. When it's done this becomes "Thought for X seconds" — click it to see how it reasoned. With Claude you can also press Ctrl+O to expand or collapse all thinking at once.
  • File edit cards: show how many lines were removed and added, with a side-by-side view of the change. Click the file path to find the file in your file manager.
  • Command cards: split into Input (the command that ran) and Output (what it printed).
  • Turn summary: after each reply there's a line showing "time taken · tokens · roughly how much it cost".
  • Copy: every message has a Copy message button.

When the AI stops to ask you

When the AI wants to change a file, run a command or needs you to decide something, a card pops up and the tab's status dot turns blue:

  • Permission prompts: for example "Allow Bash?". Click Allow once or Reject. Codex also has Allow for this session, and OpenCode also has Always allow.
  • Plan approval (Claude): Ready to implement this plan? Read the plan, then decide whether to start.
  • Questions: pick an option, or type extra details in the input box, then click Submit. Number keys 1–9 pick an option quickly.

Permission modes: how much the AI can do on its own

The permission button at the bottom of the input box decides whether the AI asks you before acting:

ToolModes (from most careful to most hands-off)
Claude CodeManual (asks before edits and commands) → Plan (proposes a plan before acting) → Edit automatically (edits files without asking, asks for everything else) → Auto (only on some models) → Bypass permissions
CodexRead only → Workspace → Full access, plus a Plan mode switch
DeepSeek HarnessWorkspace Write → Full access
OpenCodeNo permission button; you can switch the Agent instead
For beginners: start with the default mode so the AI asks you before every action. Give it more freedom once you're comfortable.

Change the model and thinking effort

  • Model: click the model name at the bottom of the input box and pick another from the menu. Each model shows its price (input / output, per million tokens).
  • Thinking effort: a slider from Faster to Smarter, with the levels Low / Medium / High / Xhigh / Max. The change takes effect when you close the menu; press Esc to discard it.

Context ring: how much more the AI can remember

The small ring at the bottom-right of the input box shows how much of the conversation's "memory" is used. It changes color past 75% and turns red past 90%. Click it to see the exact numbers.

When it's nearly full, click Continue in a new conversation inside it. This opens a fresh conversation that can look back at the old one when needed. Any half-written draft is kept and won't be sent automatically.

The "/" command menu

Type / in the input box, or click the / button, to see the commands this tool supports, such as /model (change model), /compact (compress the conversation) and /new (new conversation). Use ↑↓ to choose and Enter to run.

Worktree: experiment safely on a copy

There's a Worktree checkbox next to the folder name at the bottom of the input box. When it's checked, the AI works in a separate copy of your project (its own branch) and won't touch your original files.

  1. Check it before you send the first message. You can't change it once the conversation has started.
  2. When the AI is done, a Merge into … button appears. Click it to merge the changes back into your original project.
  3. If the changes conflict with the original project, the merge is undone automatically and your original project is left untouched.

The project folder must be a Git repository with at least one commit.

Other handy features

  • Stop: press Esc or click the square button to stop the AI at any time.
  • Quick jump: in long conversations, a column of small dots appears on the right. Each dot is one of your messages — click to jump to it.
  • Back to the latest: after scrolling up, the down arrow in the bottom-right corner takes you straight back to the newest message.
  • Prompt suggestions (Claude): when the input box is empty, gray text guesses what you'll say next. Press Tab to use it.
  • Coming back after a long break (Claude, Codex): you'll be asked whether to Resume in full or Continue in a new conversation (recommended). If the old conversation is long, the second option is faster and cheaper.
  • Load earlier messages (Claude): when you reopen a very long conversation, click this button at the top to load older messages.

09Sessions: Terminal mode

Shows the AI tool's original command-line view. Every tool except Claude Code, Codex, OpenCode, Pi and DeepSeek Harness uses this mode.

PasteCtrl/⌘+V. On Linux you can also use Ctrl+Shift+C / V
Send an image to the AIJust paste a screenshot. It's saved as a file and its path is pasted in
Refer to a fileDrag a file into the terminal to insert its path
Open linksClick a web address to open it in your browser. Click a local path to show it in your file manager (it won't be run)

The right-click menu has copy, paste and select all. Right-clicking a link or path adds options to open it or copy it. Change the terminal font and text color in Settings → Terminal.

Not used to typing in a terminal? Press Alt+W to open the input box at the bottom. Write your message there (you can paste images too), then send it to the terminal in one go.

10Input box

Where you write your requests, at the bottom of the session area. It's always shown in Desktop mode; in Terminal mode, press Alt+W to show or hide it.

Sending and new lines

  • By default, Enter sends and Shift+Enter starts a new line. If you prefer it the other way, go to Settings → General → Send message and switch to sending with Ctrl/⌘+Enter.
  • Alt+↑ / Alt+↓: bring back things you sent before.
  • Drag the top edge of the input box to change its height. The bottom-left corner shows which tool and folder your message goes to.
  • While the AI is working and the input box is empty, the send button becomes a square Stop button. In Desktop mode you can keep sending messages to add instructions while the AI works.

Send images and files

  • Paste a screenshot (Ctrl/⌘+V): a thumbnail appears above the input box. Click × to remove it.
  • Drag a file in: inserts the file's path.
  • Click the paper clip Attach files: pick files.

Save to pre-input

When there's text in the input box, Save to pre-input appears above it. If an idea isn't ready yet or the AI is busy, save it for later — then click it in Right panel → Pre-input to put it back in the input box. The trash can next to it is Clear.

Voice input

  1. Click the microphone to the left of the send button and start talking. A waveform appears next to it.
  2. Click again when you're done. The text goes into the input box so you can check it before sending.

Voice input uses an account you're already signed in to (such as Claude Code, ChatGPT or Doubao) to recognize speech. Don't see the microphone button? Go to Settings → Voice input, turn it on and scan for voice channels. On macOS you can also use the system's own speech recognition, but first turn on Dictation in "System Settings → Keyboard → Dictation".

Plan quota bar

The bottom-right of the input box shows how much of your account's quota is left. For Claude and Codex, you see the remaining percentage of your 5-hour / weekly quota and a countdown to the reset. For pay-as-you-go services like DeepSeek, Kimi and OpenRouter, you see your Balance or amount Used. It changes color when less than 30% is left. Click it to refresh.

11Split view

See up to 4 conversations side by side — handy for keeping an eye on several AIs working at once.

Two ways to open a split

  • Drag it in: in Sessions on the left, press and hold a conversation and drag it into the session area. A Split view preview appears on whichever edge you're closest to; let go to finish. Press Esc while dragging to cancel.
  • Right-click menu: right-click a conversation → Open in split view. It appears to the right of the current conversation.

Resize and close

  • Drag the divider between panes to resize them. Double-click the divider to go back to half and half.
  • Click a pane to make it the current conversation. Messages from the input box go there.
  • Each pane has a small number badge in its corner. Hover over it and it turns into ×; click it to Close split view.
  • When there are already 4 panes, you'll see Up to four sessions in split view.

12Right panel

Open it with Alt+E or the icon on the right of the title bar. It has three tabs: Pre-input, Changes and File diff.

Pre-input: save your ideas for later

  • Add: write it in the input box and click Save to pre-input above it. It becomes a note.
  • Use: click a note's text and it is added to the current conversation's input box (it isn't sent right away). Check it, then send it yourself.
  • Organize: drag notes up or down to reorder. Hover over one and a trash can appears on the right to delete it.
  • You can't edit a note directly. To change it, put it back in the input box, edit it, and save it again.

If you've set up automations, the top of the Pre-input tab shows Running automations. Click the ▶ on the right of a card to send that task to the current conversation right now.

Changes: which files the AI changed

Lists the files changed in the current conversation's project. This tab is view-only — you can't edit here.

  • The top shows the current branch name. If there's a GitHub PR, it shows the PR number, status and check results; click to open it in your browser.
  • Review scope: All changes / Uncommitted / Session commits, with the number of files and lines added and removed next to it.
  • Use Filter files… to search by path. Click a file name to open File diff; right-click to copy its path.
  • Refreshes automatically about every 8 seconds.
Don't see any changes? Three things are needed: Git is installed on your computer, the project folder is a Git repository, and a workspace is selected. If something is missing, you'll see a message such as No Git change history in this folder.

File diff: see changes line by line

  • A green + marks an added line and a red − marks a removed line. Code is syntax-highlighted.
  • Use ‹ › to move between changed files. Runs of unchanged lines are folded; click to expand them.
  • The button in the top-right corner opens the diff as a tab in the middle so it's easier to read. Press Esc to close it.
  • Markdown (.md) files are shown as formatted documents. Very large files only show the number of changed lines.

13Agent configuration

Agent configuration in the sidebar is where you manage all your AI tools. It has 6 tabs along the top.

Favorites: which tools appear on the launchpad

Click a tool card to turn it on or off. You can pick up to 6, and they show up on the launchpad. Tools with a gear icon have launch settings — click the gear to open them:

  • Command presets: Claude Code, Codex CLI and OpenCode let you pick a permission mode to start in with one click, such as Claude's Plan, Edit automatically or Bypass permissions.
  • Launch command, Extra arguments (one per line), Launch directory, Session history directory: custom options for people comfortable with the command line.
  • If you've made a mess, click Reset. When you're done, click Save.

Main memory: long-term instructions for the AI

Edit each tool's global instruction file directly, such as Claude Code's ~/.claude/CLAUDE.md or Codex's ~/.codex/AGENTS.md. Whatever you write here (for example "Always answer in English" or "Write detailed code comments"), the AI follows in every conversation. When you're done, click Save or press Ctrl/⌘+S.

Multi-agent orchestration

Choose which AIs can act as helpers and what role the main window plays. See the next section, Multi-agent orchestration.

Skills: teach the AI new abilities

  1. In the Discover tab, use Search skills.
  2. Click Install, then choose which tool to install it for.
  3. Each tool's tab lists its installed skills. Skills installed through Coffee CLI can be updated with Update or removed with Remove.

Computer Use and Browser Use

Let the AI see your screen, click and type (Computer Use), or drive a browser to open pages and click buttons (Browser Use). Both work the same way: click Check first (Browser Use needs to be installed the first time), then turn on the switch for the tools you want to use it with.

  • Computer Use currently works on Windows only.
  • Browser Use works on Windows, macOS and Linux, and needs Chrome installed.
  • Once it's on, a matching label shows at the bottom of the input box.

"Main memory" and the tabs after it only list the tools you've turned on in "Favorites".

14Multi-agent orchestration

Make Claude Code the "lead": it decides which work to hand to other AIs, opens each helper as a child tab working in parallel, and finally checks and sums up the results for you.

Turn it on

  1. Open Agent configuration → Multi-agent orchestration.
  2. Check the tools that can act as helpers: Claude Code, Codex, OpenCode, DeepSeek Harness, Pi. Tools you don't have show Not installed.
  3. Under Main window role, pick one of three (applies to main windows you open after this):
    • Decide automatically: the main window decides what to do itself and what to hand off.
    • Project manager: only splits up and assigns tasks and reviews the results; it doesn't change files itself.
    • Head chef: does the core work itself and hands side jobs to helpers.

Use it

  1. Start a new Claude Code conversation (Desktop or Terminal mode both work).
  2. The bottom of the input box shows Prefer: Decide automatically. Click it to choose a helper to prefer.
  3. Make your request as usual. When needed, cards such as "Delegate task" and "Wait for collaboration results" appear in the conversation, and helpers show up as child tabs in the title bar.

Track progress and manage helpers

  • In Sessions, a main conversation's helpers are listed beneath it: a spinner means it's working, a dot means it's waiting for you. Click one to switch to that helper.
  • When a helper shows a permission prompt, switch to its tab to handle it.
  • Right-click a helper: Open conversation, Make independent, Delete. Deleting a helper that's still running asks you to confirm first.
  • When you close a main conversation whose helpers are still running, choose Keep child sessions or End group.
No stepping on each other's toes: in a Git repository, the main window can have each helper work in its own worktree (its own branch), then merge everything together at the end.

15Automations

At the time you set, the app opens a conversation and sends the AI what you wrote ahead of time. Great for repeat jobs like a summary every morning or regular checks.

Create an automation

  1. Click Automations in the sidebar, then + New automation.
  2. Fill in Name (optional) and Prompt.
  3. Under App, choose Claude Code, Codex, DeepSeek Harness, OpenCode or Pi.
  4. Choose a Folder: pick one you've used before, or click Other folder….
  5. Set the Schedule: daily / weekdays / weekly / every so often (at least 5 minutes) / once.
  6. Click Save.

Each automation can be started with Run now, changed with Edit or removed with Delete, and paused with its switch. The list shows the next run time and the last result; click Open session to see the conversation from that run.

Two things you must know:
  • Let the AI act on its own first. Nobody is there to click "Allow" when an automation runs, so turn on automatic permissions in the tool first — for example Claude's Bypass permissions or Codex's Full access. Otherwise the task will sit waiting for approval.
  • Keep Coffee CLI open. Nothing runs while the app is closed. A missed task runs once the next time you open the app.

16Usage statistics

Usage statistics in the sidebar shows how much you've worked with AI.

  • Heatmap: messages per day over the past year. The darker the square, the more you chatted.
  • Filters: view by Today / 7 days / 30 days, by tool or by project. Click Sync to refresh by hand.
  • Stat cards: total tokens, sessions, prompts, active days and cache hit rate.
  • Charts: token trend, usage share by model, and a detailed table.

Token stats currently cover Claude Code, Codex CLI, OpenCode, Pi and DeepSeek Harness. All data comes from local records on your computer and is never uploaded.

17Settings

Click the gear at the bottom of the sidebar, or press Ctrl+, (⌘+, on macOS). Press Esc or click Back to close.

General

  • Interface scale: make everything bigger or smaller (70%–150%). If text is too small to read, adjust it here.
  • Save to pre-input button: show or hide this button.
  • Send message: choose whether Enter or Ctrl/⌘+Enter sends.
  • Toggle shortcut: shortcuts for the sidebar / input box / right panel. Choose Alt+QWE, Ctrl+QWE, Alt+123 or Ctrl+123.
  • Task complete chime, Permission prompt chime: preview or turn off each sound, or click Change to use your own MP3 / WAV (up to 20 MB).

Appearance

  • Colors: 24 color themes, each with Light, Night and Follow System (matches your system's dark / light setting) modes.
  • Shape: 10 interface styles, such as soft, sharp, glass, frosted and character rain. "Frosted" lets the desktop behind the window show through, blurred (on Linux this needs the KDE desktop).
  • Icon Style: the look of folder and file icons.
  • Wallpaper: use your own image or video as the background, and adjust its Opacity.

Terminal

  • Text color: the color of the terminal text.
  • Font: the built-in JetBrains Mono by default; you can also search for and pick a font installed on your computer.
  • Default shell: on Windows choose PowerShell, Git Bash, Command Prompt and more; on macOS / Linux choose zsh, bash and more. If you're not sure, leave it on the default.

Voice input

  • Main switch, choose a Microphone, Test microphone.
  • Dictation source: click Scan voice channels to find accounts on your computer that are signed in and can recognize speech. Ones marked "Live transcription" show text as you speak; ones marked "After recording" show it when you're done.
  • If you see "Sign-in expired", follow the hint: open that tool and send one message to renew it.

Language

18Coffee Agent

Chat with Coffee Agent over WeChat or Telegram: it can read your terminals and assign tasks, so you can keep running your computer's work from your phone.

  1. Open Settings → Coffee Agent and read the "Instructions and examples" at the top first.
  2. In Coffee Agent model configuration, choose the service type (OpenAI compatible / Anthropic compatible) and fill in the service URL, model ID and API key.
  3. Connect under Messaging channels: for WeChat, scan the QR code; for Telegram, paste the token BotFather gave you, then send the pairing code within 10 minutes.
  4. Once connected, the bottom of the sidebar shows "WeChat connected". Just message it from your phone.

Agent work modes has a few switches. With Sentinel mode on, whenever Claude Code, Codex or a similar tool finishes a turn, Coffee Agent sends you the result on WeChat or Telegram without you having to ask. Coffee CLI needs to stay running.

20Update and uninstall

Update Coffee CLI

When a new version is out, a download icon appears next to the gear at the bottom of the sidebar. Click it and the app picks a fast download source, saves the installer to your Downloads folder and verifies it, then:

  • Windows: opens the setup wizard. Just follow the steps.
  • macOS: opens the DMG. Drag Coffee CLI into Applications to replace the old version.
  • Linux: opens your Downloads folder. Double-click the .deb or .rpm to install it.

If the download fails, the website opens so you can download it by hand. You can also just run the install command again — it installs the latest version.

Uninstall

  • Windows: uninstall Coffee CLI from "Settings → Apps". The uninstaller lets you choose whether to delete the app's data too.
  • macOS: drag Coffee CLI from Applications to the Trash.
  • Linux: run sudo apt remove coffee-cli or sudo dnf remove coffee-cli.

Uninstalling Coffee CLI doesn't remove the AI tools you installed or their conversation history.

21FAQ

A tool on the launchpad is gray?

That means the tool wasn't found. First make sure you installed it following the tool's website, then switch back to the Coffee CLI window so it checks again. Still gray after installing? See Can't detect? at the bottom of the launchpad.

macOS says the app "is damaged and can't be opened"?

Run xattr -cr '/Applications/Coffee CLI.app' in Terminal, then open the app again. See Download and install for details.

Does it cost anything?

Coffee CLI is free and open source. The AI tools themselves (such as Claude or Codex subscriptions or API usage) are billed by each provider under their own terms — that has nothing to do with Coffee CLI.

"Changes" on the right is empty?

Git needs to be installed on your computer, and the project folder needs to be a Git repository. If you don't know Git, just ask the AI: "Turn this folder into a Git repository for me."

An automation's time came but nothing happened?

The most common reason is that the task is stuck "waiting for approval": turn on automatic permissions in that tool. Also, Coffee CLI needs to stay open.

No microphone button / voice input fails?

Go to Settings → Voice input: turn it on, click Scan voice channels, and make sure at least one channel is available. To use the system voice on macOS, first turn on Dictation in "System Settings → Keyboard → Dictation".

Does deleting a session delete the chat history?

No. Deleting only hides it from the list; the log files saved by the AI tool are still there.

What if the AI breaks my files?

Build two habits. First, work in a Git repository, so you can always see what changed in Changes and undo it if needed. Second, for tasks you're unsure about, check Worktree so the AI works on a copy, and merge only when you're happy.

Something else?

Ask on GitHub or email hi@coffeecli.com.
