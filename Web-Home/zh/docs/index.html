Coffee CLI 使用文档

从零开始，把 AI 编程工具用顺手

这份文档按软件里的界面一页一页地讲：每个按钮在哪里、点了会发生什么、有哪些要注意的地方。不需要编程基础，跟着「五分钟上手」走一遍，就能开始用。

下载与安装Windows / macOS / Linux，一条命令或一个安装包 五分钟上手打开软件、选工具、选文件夹、发第一条消息 界面总览先认识五个区域，后面就不会迷路 常见问题工具是灰色的？macOS 提示已损坏？

01认识 Coffee CLI

Claude Code、Codex、OpenCode 这类 AI 编程工具，原本都要在黑底白字的「终端」里用。Coffee CLI 给它们配了一个桌面：免费、开源，所有工具集中在一个窗口里管理。

  • 一个窗口管理多个 AI：支持 20 多款 AI 工具，每个对话是一个标签页，随时切换。
  • 两种用法：Claude Code、Codex、OpenCode、Pi 可以用「桌面对话」界面，像聊天软件一样用；也可以切回原汁原味的终端。
  • 分屏同时看：最多 4 个对话并排显示，谁在干活一眼就能看到。
  • 多个 AI 一起干活：让 Claude Code 当主管，把任务分给其他 AI 同时做。
  • 看清 AI 改了什么：右侧栏列出所有改动的文件，逐行显示新增和删除。
  • 额度和余额：在输入框旁边直接看到 Claude、Codex 的剩余额度，或 DeepSeek 等服务的账户余额。
先说明一点：Coffee CLI 本身不提供 AI 模型。你需要先在电脑上装好想用的 AI 工具（比如 Claude Code），并按那个工具自己的方式登录，Coffee CLI 会自动识别它。

02下载与安装

两种方式任选：在官网点按钮下载安装包，或者复制一行命令自动安装。

方式一：下载安装包

打开 coffeecli.com，点击你的系统对应的按钮：

系统安装包说明
Windows.exe（另有 .msi）x64 电脑。双击安装，缺少 WebView2 时安装程序会自动补装。
macOS.dmgApple 芯片和 Intel 芯片都支持。打开后把 Coffee CLI 拖进「应用程序」。
Linux.deb / .rpmx64 和 arm64。Ubuntu / Debian 用 .deb，Fedora / openSUSE 等用 .rpm。

Intel Mac、ARM Linux 等其他版本，在官网下载按钮下方的「更多版本」里找。国内用户在简体中文官网还能看到 百度网盘、夸克网盘、123云盘 三个下载渠道。

方式二：一行命令安装

Windowsiwr -useb https://coffeecli.com/install.ps1 | iex
macOS / Linuxcurl -fsSL https://coffeecli.com/install.sh | sh
  • Windows：右键「开始」菜单 → 选择「终端（管理员）」→ 粘贴上面的命令，回车。
  • macOS：打开「终端」应用，粘贴命令，回车。脚本会自动安装到「应用程序」。
  • Linux：在终端里运行，安装 .deb / .rpm 时会要求输入密码。

已经是最新版时，脚本会直接告诉你，不会重复安装。如果提示新版本刚发布、安装包还在上传，等十来分钟再运行一次即可。

macOS 提示「已损坏」或打不开？这是系统对网上下载应用的拦截，不是文件真的坏了。打开「终端」，运行下面这行，然后重新打开 Coffee CLI：
xattr -cr '/Applications/Coffee CLI.app'

03五分钟上手

以 Claude Code 为例，从打开软件到让 AI 帮你干活。

  1. 装好 AI 工具。Coffee CLI 只负责「管理」，AI 工具要自己装。比如 Claude Code，按它官网的说明安装并登录一次。
  2. 打开 Coffee CLI。第一次打开就会看到「启动台」，上面有几张工具卡片。已安装的工具是亮的，没装的是灰色。
  3. 点 Claude Code 卡片，选一个文件夹。这个文件夹就是 AI 干活的地方，它能读、能改里面的文件。建议先新建一个空文件夹来练手。
  4. 在底部输入框里写需求，按 Enter 发送。比如「帮我做一个记账的网页」。AI 开始工作时，标签页上的小点会变成橙色。
  5. 处理 AI 的提问。AI 想改文件或运行命令时，可能会停下来问你。点 允许一次 让它继续，点 拒绝 不让它做。
  6. 看结果。按 Alt+E 打开右侧栏，在 修改记录 里查看 AI 改了哪些文件（需要文件夹是 Git 仓库）。
小技巧：左侧的 会话记录 会保存所有对话。下次打开软件，点一下就能接着上次聊。

左侧栏、输入框、右侧栏都可以随时隐藏，让会话区更宽：

05启动台

新建会话时看到的页面，用来选「哪个 AI」在「哪个文件夹」里工作。

打开启动台

点左侧栏顶部的 新建会话，或者标题栏标签条末尾的 +。如果已经有一个还没选工具的空白标签，会直接切过去，不会再开新的。

启动一个 AI 工具

  1. 点工具卡片。
  2. 如果这个工具以前用过，卡片上会显示上次的文件夹路径，点一下就直接在那里启动。
  3. 第一次用时卡片上写着 选择项目目录：会弹出最近用过的文件夹列表，最下面是 打开文件夹，可以选新的文件夹。
  4. 想换文件夹，点卡片右边的文件夹按钮。最近列表里的每一项都可以点 × 删掉。

OpenClaw 不需要选文件夹，点一下就启动。之前用过的文件夹被删除或移动后，会自动从列表里去掉。

桌面对话还是终端？

Claude Code、Codex CLI、OpenCode、Pi 的卡片上有 Desktop / Terminal 切换：

  • Desktop（默认）：像聊天软件一样的界面，有按钮可以点，适合新手。详见 桌面对话模式。
  • Terminal：工具原本的命令行界面，适合熟悉终端的用户。详见 终端模式。

DeepSeek Harness 只有桌面模式，其余工具都在终端里运行。你的选择会被记住，从会话记录恢复对话时也按这个模式打开。

支持哪些工具

Claude Code、Codex CLI、DeepSeek Harness、Cursor、Copilot CLI、Antigravity CLI、OpenClaw、Hermes Agent、OpenCode、Pi、Cline、Goose、Aider、Oh-My-Pi、Crush、Qwen Code、Kilo Code、Kiro、Kimi Code、CodeBuddy、Grok Build、MiMo Code、MiniMax Code、Muse Code，再加一个普通的 终端。

启动台最多同时摆 6 张卡片，第一次默认是 Claude Code、Codex CLI、OpenCode、Pi、DeepSeek Harness 和终端。想换成别的工具，去 应用配置 → 常用。

工具是灰色的，点不动

说明 Coffee CLI 没在电脑上找到这个工具。启动台不负责安装，你需要按那个工具官网的说明自己装。装好后切回 Coffee CLI 窗口，会自动重新检测。

明明装了还是灰的？把鼠标放到启动台底部的 识别不到? 上，会显示原因和三种修复办法。常见原因是电脑的环境变量 PATH 被其他工具改坏了。

更新 AI 工具

工具有新版本时，卡片上会出现 更新 按钮，鼠标放上去能看到从哪个版本升到哪个版本。点击后显示 更新中。软件会按你当初的安装方式（npm、Homebrew 等）自动更新。

远程终端

点 终端 卡片上的 远程，可以连接另一台电脑或服务器：选 SSH 或 WebSocket，填 服务器地址、端口、用户名、密码，点 连接。最近 10 次连接会显示成小标签，点一下就能重连。

注意：远程连接的密码会以明文保存在本机（~/.coffee-cli/credentials.json）。公用电脑上请不要保存重要密码。

06标题栏

窗口最上面一条，主要是打开的会话标签。

会话标签

  • 每个打开的对话是一个标签，显示工具图标和项目文件夹名。点击切换，左右拖动可以调整顺序，点 × 关闭。
  • 还没选工具的空白标签叫 选择工具。
  • 双击标题栏空白处可以最大化或还原窗口，按住空白处拖动可以移动窗口。

状态点：一眼看出 AI 在干嘛

标签右边有一组小点，颜色表示 AI 的状态：

颜色意思你需要做什么
绿色空闲 / 已完成可以看结果或发下一条消息
橙色工作中等它干完就行
蓝色等你操作切过去处理权限确认或回答它的问题

Linux 上只显示一个不动的彩色圆点，没有动画。任务完成和等待你操作时还会响提示音，可以在 设置 → 通用 里更换或关闭。

其他按钮

  • 更新日志：查看当前版本更新了什么。软件升级后第一次打开会自动弹出一次。
  • 三个面板开关：左侧栏、输入框、右侧栏，见 界面总览。
  • 设置：平时在左侧栏底部；左侧栏隐藏时，会出现在标题栏上。
  • Windows / Linux 的最小化、最大化、关闭按钮在最右边；macOS 用系统自带的红黄绿按钮。

07左侧栏

管理所有对话和项目文件。顶部有 新建会话 和两个视图切换：会话记录、工作区。

会话记录：所有历史对话

  • 接着聊：点任意一条。对话已经开着会直接切过去；没开的话会新开一个标签，在原来的文件夹里继续。
  • 找对话：点 搜索，可以按标题、工具名、项目路径查找。用 ↑↓ 选择，Enter 打开，Esc 关闭。
  • 换个排列方式：右上角漏斗图标是 显示方式：
    • 会话列表：看全部，或只看某一个工具的对话。
    • 项目分类：按文件夹分组。可选 全部目录 或 仅已添加，每组先显示 5 条，点 显示更多 展开。
    • 应用图标：选择显示或不显示工具图标。
  • 正在运行的对话会排在最上面，接着是置顶的对话。鼠标悬停能看到项目名、时间和消息条数。

对话卡片上的小标记

标记意思
转圈工作中
蓝色标签等待操作：AI 在等你确认
蓝色小圆点新答复未读
PR 图标这个对话的分支有 GitHub PR。绿色 = 待合并，紫色 = 已合并，红色 = 已关闭；角上的 ✓ / × / · 分别是检查通过、失败、运行中

右键菜单

  • 在分屏中打开：在当前对话右边分屏显示，见 分屏。
  • 置顶 / 取消置顶、重命名（按 Enter 保存，Esc 取消）。
  • 复制会话ID、复制恢复命令：想在别的终端里接着这个对话时用。
  • 复制完整路径、在文件管理器中显示：找到这个对话的记录文件。
  • 删除：鼠标悬停时出现的垃圾桶按钮效果一样。
放心删：「删除」只是把对话从列表里隐藏，不会删掉 AI 工具自己保存的记录文件。如果这个对话正开着，它的标签会一起关闭。

工作区：项目文件

  • 显示当前对话所在文件夹里的文件，文件有变化会自动刷新。
  • 有未提交改动的文件后面会显示 +N -M（新增和删除的行数）。
  • 点放大镜可以 筛选文件和文件夹…（只筛第一层）。
  • 右键文件：打开（用系统默认程序）、复制绝对路径、复制相对路径、复制为 @reference、剪切 / 复制 / 粘贴、重命名、删除、在文件管理器中显示。
让 AI 看某个文件：右键文件 → 复制为 @reference，粘贴到输入框里，AI 就知道你说的是哪个文件。

底部按钮

  • Coffee Agent 和消息渠道状态（例如「微信 · 未连接」），见 Coffee Agent。
  • 下载图标：Coffee CLI 有新版本时才出现，见 更新与卸载。
  • 齿轮：打开 设置。

左侧栏顶部还有 应用配置、使用统计、自动化 三个入口，分别见后面的「功能页面」。

08会话：桌面对话模式

Claude Code、Codex、OpenCode、Pi、DeepSeek Harness 可以用这种像聊天软件一样的界面。不用记命令，大部分操作点按钮就行。

看懂 AI 的回复

  • 思考过程：AI 想问题时显示 正在思考中…，想完变成「思考了 X 秒」，点一下能展开看它怎么想的。Claude 还可以按 Ctrl+O 一次展开或收起全部思考。
  • 改文件卡片：显示删了几行、加了几行，并左右对比显示改动。点文件路径会在文件管理器里找到它。
  • 运行命令卡片：分 输入（运行了什么命令）和 输出（命令的结果）两部分。
  • 每轮小结：每次回复结束后，下面有一行「耗时 · 词元数 · 大约花了多少钱」。
  • 复制：每条消息旁边都有 复制消息 按钮。

AI 停下来问你时

AI 想改文件、运行命令，或者需要你做决定时，会弹出一张卡片，标签上的状态点同时变成蓝色：

  • 权限确认：例如「允许 Bash 吗？」。点 允许一次 或 拒绝。Codex 还有 本次会话允许，OpenCode 还有 始终允许。
  • 计划确认（Claude）：准备实施这个计划吗？ 看完计划再决定要不要开始。
  • 提问：选一个选项，或在输入框里写补充说明，再点 提交。可以用数字键 1–9 快速选择。

权限模式：AI 能自己做多少事

输入框底部的权限按钮决定 AI 动手前要不要问你：

工具可选档位（从谨慎到放手）
Claude Code手动（编辑和运行命令前都问）→ 计划（先出方案再动手）→ 自动编辑（改文件不问，其他问）→ 自动（部分模型才有）→ 跳过权限确认
Codex只读 → 工作区 → 完全访问；另有 计划模式 开关
DeepSeek Harness工作区内修改 → 完全权限
OpenCode没有权限按钮，可切换 智能体
新手建议：先用默认档位，让 AI 每次动手前都问你。熟悉之后再放开权限。

换模型和思考强度

  • 模型：点输入框底部的模型名，从菜单里换。每个模型后面标着价格（输入 / 输出，每百万 token）。
  • 思考强度：一根滑杆，从 更快 到 更深入，档位有 低 / 中 / 高 / 超高 / 最高。关闭菜单后才生效，按 Esc 放弃修改。

上下文圆环：AI 还能记住多少

输入框右下角的小圆环表示这个对话用掉了多少「记忆空间」。超过 75% 会变色提醒，超过 90% 变成红色。点开能看到具体用量。

快满时，可以点里面的 开新对话继续：开一个新对话，需要时让它回头查阅旧记录，你写了一半的草稿也会保留，不会自动发送。

「/」命令菜单

在输入框里打 /，或点 / 按钮，会弹出这个工具支持的命令，比如 /model（换模型）、/compact（压缩对话）、/new（新对话）。用 ↑↓ 选择，Enter 执行。

工作树：在副本里放心试

输入框底部文件夹名旁边的 工作树 复选框。勾上后，AI 会在项目的一份独立副本（单独的分支）里工作，不会动你原来的文件。

  1. 发第一条消息之前勾选。对话开始后就不能改了。
  2. AI 干完活后，出现 合并到 … 按钮。点它把改动合并回原来的项目。
  3. 如果和原项目冲突，会自动撤销这次合并，原项目不受影响。

需要项目文件夹是 Git 仓库，并且至少有一次提交。

其他贴心功能

  • 停止：按 Esc 或点方块按钮，随时让 AI 停下。
  • 快速定位：对话变长后，右侧会出现一列小圆点，每个代表你的一次提问，点击就能跳过去。
  • 回到最新：往上翻后，右下角的向下箭头可以一键回到最新消息。
  • 提示词建议（Claude）：输入框为空时，灰字会猜你下一句想说什么，按 Tab 采用。
  • 闲置很久后回来（Claude、Codex）：会问你是 完整恢复 还是 开新对话继续（推荐）。旧对话很长时选后者更快更省。
  • 加载更早的消息（Claude）：恢复很长的旧对话时，在顶部点这个按钮加载更早的内容。

09会话：终端模式

直接显示 AI 工具原本的命令行界面。除 Claude Code、Codex、OpenCode、Pi、DeepSeek Harness 外，其他工具都用这种模式。

想做什么怎么做
复制选中文字，按 Ctrl/⌘+C。没有选中文字时，Ctrl+C 是中断当前程序
粘贴Ctrl/⌘+V。Linux 也可以用 Ctrl+Shift+C / V
发图片给 AI直接粘贴截图，会自动存成文件并粘贴它的路径
引用文件把文件拖进终端，会插入文件路径
打开链接点网址用浏览器打开；点本地路径会在文件管理器里显示它（不会运行）
翻看历史可往回翻最近 5000 行，翻上去后有「返回最新消息」按钮

右键菜单有复制、粘贴、全选；右键点在链接或路径上，还会多出打开和复制链接的选项。终端字体和文字颜色在 设置 → 终端 里改。

不习惯在终端里打字？按 Alt+W 打开底部输入框，在里面写好、可以贴图片，再一次性发给终端。

10输入框

会话区最下面写需求的地方。桌面对话模式下一直显示，终端模式下用 Alt+W 打开或隐藏。

发送和换行

  • 默认 Enter 发送，Shift+Enter 换行。习惯反过来的，去 设置 → 通用 → 发送消息 改成 Ctrl/⌘+Enter 发送。
  • Alt+↑ / Alt+↓：翻出以前发过的内容。
  • 拖动输入框上边缘可以调高度。输入框左下角显示消息会发到哪个工具、哪个文件夹。
  • AI 工作时输入框为空，发送按钮会变成方块 停止。桌面对话模式下，AI 工作时也可以继续发消息补充要求。

发图片和文件

  • 截图后直接粘贴（Ctrl/⌘+V）：输入框上方会出现缩略图，点 × 可以移除。
  • 拖文件进来：会插入文件路径。
  • 点回形针 添加附件：选择文件。

保存到预输入

输入框里有字时，上方会出现 保存到预输入。想法还没想好、或者 AI 正忙，先存起来，之后在 右侧栏 → 预输入 里点一下就能放回输入框。旁边的垃圾桶是 清空。

语音输入

  1. 点发送按钮左边的麦克风，开始说话，旁边会出现波形。
  2. 说完再点一下，文字会写进输入框，确认后再发送。

语音输入借用你已登录的账号（比如 Claude Code、ChatGPT、豆包）来识别。看不到麦克风按钮？去 设置 → 语音输入 打开开关并扫描语音渠道。macOS 也可以用系统自带的语音识别，但要先在「系统设置 → 键盘 → 听写」中开启听写。

套餐额度条

输入框底部右侧显示账号还剩多少额度：Claude、Codex 显示 5 小时 / 每周额度的剩余百分比和重置倒计时；DeepSeek、Kimi、OpenRouter 等按量付费的服务显示 余额 或 已用。剩余不足 30% 会变色提醒，点一下可以刷新。

11分屏

同时并排看最多 4 个对话，适合几个 AI 一起干活时盯进度。

开分屏的两种方法

  • 拖进来：在左侧 会话记录 里按住一个对话，拖到中间会话区。靠近哪条边，就在哪一侧显示 分屏显示 的预览，松手完成。拖动时按 Esc 取消。
  • 右键菜单：右键对话 → 在分屏中打开，它会出现在当前对话的右侧。

调整和关闭

  • 拖动窗格之间的分隔条调大小；双击分隔条恢复一半对一半。
  • 点哪个窗格，哪个就是当前对话，输入框的消息会发到这里。
  • 每个窗格角上有编号小标，鼠标放上去变成 ×，点它 关闭分屏。
  • 已经有 4 个窗格时，会提示 最多同时显示四个会话。

12右侧栏

用 Alt+E 或标题栏右边的图标打开。有三个标签：预输入、修改记录、文件对比。

预输入：先把想法存起来

  • 添加：在输入框里写好，点上方的 保存到预输入，就变成一张便签。
  • 使用：点便签正文，内容会追加到当前对话的输入框里（不会直接发出），确认后自己发送。
  • 整理：上下拖动调整顺序；鼠标移上去，右边出现垃圾桶可以删除。
  • 便签不能直接改字。想改的话，先放回输入框，改好后重新保存。

如果设置了 自动化，预输入页顶部会显示 正在自动化，点卡片右边的 ▶ 可以把这条任务立刻发给当前对话。

修改记录：AI 改了哪些文件

列出当前对话所在项目里改过的文件。这一页只能看，不能改。

  • 顶部显示当前分支名；如果有 GitHub PR，会显示 PR 编号、状态和检查结果，点击在浏览器里打开。
  • 查看范围：全部修改 / 未提交 / 本次会话提交，旁边统计文件数和增删行数。
  • 用 筛选文件… 按路径查找。点文件名打开 文件对比，右键可以复制路径。
  • 大约每 8 秒自动刷新一次。
看不到修改记录？需要满足三个条件：电脑装了 Git；项目文件夹是一个 Git 仓库；已经选好了工作区。不满足时会显示相应提示，比如 此目录暂无 Git 修改记录。

文件对比：逐行看改动

  • 绿色 + 是新增的行，红色 − 是删除的行，代码会按语法上色。
  • 用 ‹ › 在改动的文件之间切换。连续没改的行会折叠，点一下展开。
  • 右上角的按钮可以把对比放大成中间的一个标签页，看得更清楚；按 Esc 关闭。
  • Markdown（.md）文件会直接显示排好版的文档。文件太大时只显示改动行数。

13应用配置

左侧栏的 应用配置，集中管理所有 AI 工具。顶部有 6 个分页。

常用：启动台摆哪些工具

点工具卡片打开或关闭，最多选 6 个，会显示在启动台上。带齿轮的工具可以点齿轮打开启动设置：

  • 预设启动命令：Claude Code、Codex CLI、OpenCode 可以一键选择启动时的权限档位，比如 Claude 的 计划、自动编辑、跳过权限确认。
  • 启动命令、额外参数（每行一个）、启动目录、历史对话目录：给熟悉命令行的用户自定义。
  • 改乱了点 重置，改好点 保存。

主记忆：给 AI 的长期说明

直接编辑每个工具的全局说明文件，比如 Claude Code 的 ~/.claude/CLAUDE.md、Codex 的 ~/.codex/AGENTS.md。写在这里的话（例如「回答请用中文」「代码注释写详细一点」），AI 每次对话都会遵守。改完点 保存 或按 Ctrl/⌘+S。

多智能体编排

选哪些 AI 可以当助手，以及主窗口的角色，详见下一节 多智能体编排。

技能：给 AI 装新本领

  1. 在 发现 分页里 搜索技能。
  2. 点 安装，再选要装到哪个工具。
  3. 每个工具的分页列出已装的技能，通过 Coffee CLI 装的可以 更新 或 卸载。

电脑控制 与 浏览器控制

让 AI 能看屏幕、点鼠标、打字（电脑控制），或者操作浏览器打开网页、点按钮（浏览器控制）。用法都是：先点 检测（浏览器控制第一次要先点安装），再打开要用的工具的开关。

  • 电脑控制目前只支持 Windows。
  • 浏览器控制支持 Windows、macOS、Linux，需要先装好 Chrome 浏览器。
  • 开启后，输入框底部会显示对应标签。

「主记忆」及之后的分页，只列出在「常用」里打开的工具。

14多智能体编排

让 Claude Code 当「主管」：它自己判断哪些活交给其他 AI，每个助手开成一个子标签同时干活，最后由它检查、汇总结果给你。

开启

  1. 打开 应用配置 → 多智能体编排。
  2. 勾选可以当助手的工具：Claude Code、Codex、OpenCode、DeepSeek Harness、Pi。没装的会显示 未安装。
  3. 在 主窗口角色 里三选一（对之后新开的主窗口生效）：
    • 自主决策：主窗口自己判断哪些自己做、哪些分出去。
    • 项目经理：只拆分和分派任务、审核结果，自己不改文件。
    • 主厨：核心部分亲自做，周边杂活交给助手。

使用

  1. 新建一个 Claude Code 对话（桌面或终端模式都行）。
  2. 输入框底部会显示 优先协作：自主决策，点开可以指定优先用某个助手。
  3. 像平常一样提需求。需要时，对话里会出现「派发协作任务」「等待协作结果」等卡片，助手以子标签的形式出现在标题栏。

看进度、管理助手

  • 在 会话记录 里，主对话下方会列出它的助手：转圈是在工作，圆点表示等你操作。点一下切到那个助手。
  • 助手弹出权限确认时，需要切到它的标签里处理。
  • 右键助手：打开原会话、转为独立会话、删除。删除还在运行的助手会先请你确认。
  • 关闭还有助手在运行的主对话时，可以选 保留子会话 或 结束整组。
改动不打架：在 Git 仓库里，主窗口可以让每个助手在独立的工作树（单独的分支）上干活，最后由主窗口统一合并。

15自动化

到了设定的时间，自动打开一个对话，把你写好的内容发给 AI。适合每天早上自动总结、定时检查之类的重复工作。

新建一条自动化

  1. 点左侧栏的 自动化，再点 + 新建自动化。
  2. 填 名称（可不填）和 要发送的内容。
  3. 在 应用 里选 Claude Code、Codex、DeepSeek Harness、OpenCode 或 Pi。
  4. 选 工作目录：从用过的文件夹里挑，或点 其他目录…。
  5. 设 时间：每天 / 工作日 / 每周 / 每隔（最少 5 分钟）/ 一次。
  6. 点 保存。

每条自动化都可以 立即运行、编辑、删除，用开关暂停。列表里显示下次运行时间和上次结果，点 查看会话 可以看那次运行的对话。

两个必须知道的点：
  • 先给 AI 开自动执行权限。到点运行时没人在旁边点「允许」，请先在对应工具里开启，例如 Claude 的 跳过权限确认、Codex 的 完全访问，否则任务会一直停在等待批准。
  • Coffee CLI 要开着。软件关闭期间不会运行；错过的任务会在下次打开软件后补跑一次。

16使用统计

左侧栏的 使用统计，看你和 AI 一起工作了多少。

  • 热力图：近一年每天的消息数，颜色越深聊得越多。
  • 筛选：按 今日 / 近 7 天 / 近 30 天、按工具、按项目查看。点 同步 手动刷新。
  • 数据卡片：Token 总量、会话数、提问次数、活跃天数、缓存命中率。
  • 图表：Token 趋势、各模型用量占比和明细表。

Token 统计目前支持 Claude Code、Codex CLI、OpenCode、Pi、DeepSeek Harness。数据都来自你电脑上的本地记录，不会上传。

17设置

点左侧栏底部的齿轮，或按 Ctrl+,（macOS 是 ⌘+,）。按 Esc 或点 返回 关闭。

通用

  • 界面缩放：整体放大缩小（70%–150%），字太小看不清就调这里。
  • 输入框的“保存到预输入”按钮：显示或隐藏这个按钮。
  • 发送消息：选 Enter 发送还是 Ctrl/⌘+Enter 发送。
  • 开关快捷键：左侧栏 / 输入框 / 右侧栏的快捷键，可选 Alt+QWE、Ctrl+QWE、Alt+123、Ctrl+123。
  • 任务完成提示音、等待权限提示音：可以试听、关闭，或点 更换 用自己的 MP3 / WAV（20 MB 以内）。

外观

  • 配色：24 套配色，每套都有 明亮、夜晚、跟随主题（跟随系统深色 / 浅色）三种模式。
  • 形态：10 种界面风格，比如柔和、锐角、玻璃、磨砂、字符流。「磨砂」会让窗口背后的桌面透出来变模糊（Linux 需要 KDE 桌面）。
  • 图标风格：文件夹和文件图标的样式。
  • 壁纸：用自己的图片或视频当背景，可以调 透明度。

终端

  • 文字颜色：终端文字的颜色。
  • 字体：默认是内置的 JetBrains Mono，也可以搜索选择电脑上装的字体。
  • 默认终端：Windows 可选 PowerShell、Git Bash、命令提示符等；macOS / Linux 可选 zsh、bash 等。不确定就保持 Auto。

语音输入

  • 总开关、选择 麦克风、测试麦克风。
  • 语音渠道：点 扫描语音渠道，找出电脑上已登录、能用来识别语音的账号。标「实时转写」的边说边出字，标「录完转写」的说完才出字。
  • 提示「登录已过期」时，按提示打开对应工具发一条消息即可续期。

语言

界面支持 11 种语言：English、简体中文、繁體中文、日本語、한국어、Español、Français、Deutsch、Português、Русский、Tiếng Việt，点一下立即切换。

BUG / 建议

遇到问题或有想法，从这里提交到 GitHub。简体中文界面还提供国内可访问的 GitCode 入口。

18Coffee Agent

通过微信或 Telegram 与 Coffee Agent 对话：读取终端、安排任务，在手机上继续接管电脑上的工作。

  1. 打开 设置 → Coffee Agent，先读一遍顶部的「使用说明」。
  2. 在 Coffee Agent 模型配置 里选服务类型（OpenAI 兼容 / Anthropic 兼容），填服务地址、模型 ID、API 密钥。
  3. 在 消息渠道 里连接：微信扫码；Telegram 粘贴 BotFather 给的 Token，再在 10 分钟内发送配对码。
  4. 连接成功后，左侧栏底部会显示「微信已连接」，在手机上给它发消息即可。

工作方式 里有几个开关，其中 哨兵模式 打开后，Claude Code、Codex 等工具每轮工作结束时，Coffee Agent 会主动把结果发到你的微信或 Telegram，不用你先问。需要保持 Coffee CLI 运行。

20更新与卸载

更新 Coffee CLI

有新版本时，左侧栏底部齿轮旁会出现一个下载图标。点它后会自动挑一个快的下载源，下载到「下载」文件夹并校验，然后：

  • Windows：自动打开安装向导，按提示完成即可。
  • macOS：自动打开 DMG，把 Coffee CLI 拖进「应用程序」替换旧版。
  • Linux：打开「下载」文件夹，双击 .deb 或 .rpm 安装。

下载失败时会自动打开官网，手动下载即可。也可以重新运行 安装命令，它会装上最新版。

卸载

  • Windows：在「设置 → 应用」里卸载 Coffee CLI。卸载界面可以勾选是否同时删除应用数据。
  • macOS：把「应用程序」里的 Coffee CLI 拖到废纸篓。
  • Linux：运行 sudo apt remove coffee-cli 或 sudo dnf remove coffee-cli。

卸载 Coffee CLI 不会删除你装的 AI 工具，也不会删除它们的对话记录。

21常见问题

启动台上的工具是灰色的？

说明没找到这个工具。先确认已经按工具官网的说明装好，再切回 Coffee CLI 窗口让它重新检测。装了还是灰的，看启动台底部的 识别不到?。

macOS 提示「已损坏，无法打开」？

在「终端」里运行 xattr -cr '/Applications/Coffee CLI.app'，然后重新打开。详见 下载与安装。

需要付费吗？

Coffee CLI 免费、开源。AI 工具本身的费用（比如 Claude、Codex 的订阅或 API 费用）按各家的规则收取，与 Coffee CLI 无关。

右侧「修改记录」什么都没有？

需要电脑装了 Git，并且项目文件夹是 Git 仓库。不熟悉 Git 的话，可以直接让 AI 帮你：「帮我把这个文件夹初始化成 Git 仓库」。

自动化到点了却没动静？

最常见的原因是任务停在「等待批准」：请在对应工具里开启自动执行权限。另外，Coffee CLI 需要保持打开。

看不到麦克风按钮 / 语音输入失败？

去 设置 → 语音输入：打开开关，点 扫描语音渠道，确认至少有一个可用的渠道。macOS 用系统语音时，要先在「系统设置 → 键盘 → 听写」中开启听写。

删除会话会不会把聊天记录删掉？

不会。删除只是从列表里隐藏，AI 工具自己保存的记录文件还在。

AI 改坏了我的文件怎么办？

养成两个习惯：一是在 Git 仓库里工作，随时能在 修改记录 里看到改了什么、需要时可以撤回；二是对没把握的任务勾选 工作树，让 AI 在副本里改，满意了再合并。

还有其他问题？

到 GitHub 或 GitCode（国内） 提问，或发邮件到 hi@coffeecli.com。

文档对应 Coffee CLI v4.0.0。界面上的按钮名称以软件简体中文版为准；发现文档和软件对不上，欢迎 反馈给我们。
